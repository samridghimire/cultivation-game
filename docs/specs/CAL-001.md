# CAL-001: The month ahead (core)

Role: systems. Reference: Immortal Life's village calendar (market days, birthdays and festivals on one page); mechanics only.
Feeds WU-419 (the calendar screen). No new state, no save change, no balance effect (no `tools/balance.sh` run needed).

## What exists
- `Places.is_open / days_until_open` (MARKET-002, `open_days` on places, src/core/systems/places.gd).
- `Folk.birthday_day / days_to_birthday / birthdays_soon` (FOLK-008, src/core/systems/folk.gd ~496).
- `data/world_events.json`: festivals have `"festival": true` and fixed `months` with `monthly_chance` 1.0; the region is
  picked when the event starts (`WorldEvents.roll`), so a future festival's region is unknown. Active instances live in
  `GameState.world_events` (`{id, region, start_day, end_day}`).
- `Calendar` (src/core/calendar.gd): `DAYS_PER_MONTH`, `month_of`, `day_of`, `season_of`, `format_date`.

## New: src/core/systems/village_calendar.gd (`class_name VillageCalendar`, RefCounted, static funcs)
```
## Every dated thing in [start, start + span) days that the player can know about, soonest first.
## Each entry: {day: int (total days), kind: String, text: String, region: String ("" = anywhere)}.
static func upcoming(data: GameData, npcs: Dictionary, favor: Dictionary, active_events: Array,
		region_id: String, start: int, span: int = 30) -> Array[Dictionary]
static func month_grid(entries: Array, month_start: int) -> Dictionary  # day_of_month (1..30) -> Array[Dictionary]
static func month_start(total_days: int) -> int  # total days of day 1 of that month
```
Kinds and texts (keep texts short, they go in grid cells and a list):
- `market`: every timed place (`open_days`) in `region_id` on each open day: "Market: Travelling Market Stall".
- `birthday`: generated villagers of `region_id` with favor >= 10 (reuse `birthdays_soon(..., span)`): "Xiao Ling's birthday".
- `festival_active`: each active world event with `festival: true` (any region), every day from max(start, start_day)
  to end_day - 1, one entry per event (put it on its first visible day only, with text "Lantern Festival in Qingshi
  Village (until Month 1, Day 9)").
- `festival_month`: a festival def whose `months` contains the month of a day in the window and which is not active yet:
  one entry on day 1 of that month: "Lantern Festival this month (somewhere in <region names joined with " or ">)".
- `season`: the first day of a new season inside the window: "Winter begins".
Ties on the same day sort by kind order market, festival_active, festival_month, birthday, season, then text.

## GameState
`func upcoming_days(span: int = 30) -> Array[Dictionary]` — a thin wrapper with the current region and today.
No posting, no time.

## Tests (tests/unit/test_village_calendar.gd)
- market days of the Qingshi stall (10 and 25) appear for a window covering a whole month, none for a region without one.
- a villager at favor 9 has no birthday entry, at 10 does, on the day `days_to_birthday` says.
- an active festival shows once with its end date; a festival month in the window shows once on day 1; it does not show
  as `festival_month` while it is active.
- season entry on the right day; sorting order on a shared day; `month_grid` buckets by day of month.
- GameState integration in test_game_session.gd: `upcoming_days()` in a fresh session returns the stall's next market day.
