# FH-004 Sense danger and choose to flee (systems)

## Problem
`Exploration.should_evade` (src/core/systems/exploration.gd:268) only spares the player from lethal foes rated "Deadly" (<15%
win). A lethal foe rated "Dangerous" (15-50%) is forced on the player by `GameState.explore` (game_state.gd ~479), so an improving
Qi Refining player meeting a Mist Wolf at 17-43% odds dies (artifact life spent) 57-83% of the time with no say.

## Change (core + GameState; the prompt UI is FH-004b)
1. `Exploration.should_offer_flee(c, data, enemy_id) -> bool`: true when the enemy is `lethal` and
   `Combat.danger_label(...) == "Dangerous"`. (Deadly stays auto-evaded, Even/Weak fights stay forced.)
2. GameState: `var pending_threat := ""` (transient like `pending_encounter`: cleared in the same places, lines ~81/110/466, not
   saved). In `explore()`, after the evade check: if `should_offer_flee`, set `pending_threat = enemy_id`, post
   "You sense a %s nearby, hungry for a kill (%s, %d%% to win)." with Combat.win_chance rounded, emit a new signal
   `EventBus.threat_sensed(enemy_id: String)` and return.
3. `GameState.face_threat(fight_it: bool) -> void`: no-op with a warning if `pending_threat == ""` or `not _can_act()`.
   Clear `pending_threat` first. If `fight_it`: `fight(enemy_id)`. Else post "You slip away before it finds you." and
   `_pass_time(1)`.
4. Add the signal to src/autoload/event_bus.gd with a `##` comment.
5. Until FH-004b lands nobody answers the prompt, so make it safe: if any other action is taken while `pending_threat` is set
   it is simply cleared (explore() clears it at the start, like pending_encounter).

  helper `GameState._resolve_explore_enemy(enemy_id)` that explore() calls and tests call directly). Assert no fight happened
