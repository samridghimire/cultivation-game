# WU-441: The first screen is clear (world-ui)

Reference: Stardew Valley and Wandering Sword put the interaction hint next to the thing you face, never over another
name; the opening title card never hides the first person you must talk to. Mechanics only.

Planner shots 2026-11-05 at 1280x720 (`screenshot_first_hour.gd -- --arrival-card`) and GFX-065's Follow-ups:
1. The new-game arrival card ("Qingshi Village / Qi x1.0 · Danger: Safe / Today in ...") sits over **Elder Mo**, whose
   name the very first goal names ("Talk to Elder Mo in Qingshi Village"). Only his sprite's feet show.
2. The bottom-centre interact prompt ("[E] Wandering Merchant", hud.gd ~140, anchored 170-132 px above the bottom)
   covers the "Temple of Mercy (orphanage)" label; at 1280x720 the Village Workshop / Blossom Crack labels sit against
   the key strip.

## Do
1. **The arrival card never hides the goal NPC.** Either start the new game with the camera framing the player and Elder
   Mo below the card (move the start spawn or camera offset in world.gd), or show the start card lower (Banner already
   takes `low`; a low card must still not cover the player). Pick whichever is smaller. Generalise lightly: when the
   first goal names an NPC in this region, that NPC's label must be outside the card's rect.
2. **The prompt sits with its target.** Draw "[E] <name>" as a chip just above the targeted interactable's name label
   (world position -> screen via the world's canvas transform), clamped inside the screen and outside the HUD cards
   (status, Next steps, log, key strip: reuse WU-435's card rects / LabelLayout). While shown, the target's own name label
   is hidden (the chip names it), so it never doubles. Keep the bottom-centre prompt only as the fallback when the target
   has no label. Gamepad glyphs keep working (`InputConfig.current_label("interact")`).
3. Labels within ~28 px of the key strip at 720p get pushed up (LabelLayout's existing avoid rects, add the key strip).

## Tests
- A pure helper for the chip position (`Hud.prompt_rect(target_label_rect, screen, avoid_rects) -> Rect2`): above the
  label when free, clamped to the screen, never intersects an avoid rect when a free spot exists.
- New game at 1280x720 and 1280x800: Elder Mo's label rect does not intersect the arrival card rect.
- The targeted interactable's label is hidden while the chip shows and back when the target changes.
