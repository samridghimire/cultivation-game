# WU-554: what you wear, at a glance

Role: world-ui. Reference: Wandering Sword's character screen (look only: paper-doll slots beside the portrait).

## Problem
The character sheet (src/ui/character_sheet.gd) shows equipment only as text lines deep in the scrolled body
("Equipment / Weapon: none / Armor: none", ~309-315) and the Unequip buttons in `_equip_row`. The left column (portrait,
name, realm, qi bar, roots, ~98-230) ends with empty space at 1280x800 (planner shot 2026-11-16 character_sheet.png).
A newcomer can't see at a glance what they wield or that an armor slot is empty.

## Change (UI only, no rule change)
1. Under the roots block in the left column (`_build_left_column` / `_rebuild_left`), add a "Gear" strip: one
   row per `Equipment.SLOTS` entry (weapon, armor): a 32x32 framed icon (`ItemIcon.for_id(data, item_id)`, or a dim slot
   glyph drawn in code when empty), the item name (or "No weapon" / "No armor" in the muted colour) and one short
   stat line from `Equipment.describe_stats(data, item_id)` (ellipsis if it would wrap past the column width).
2. Below the rows, one line "Attack N  Defense N" from `Combat.stats(p, data)` (same numbers as the Combat section).
3. Each filled row is a focusable button (UIStyle button look, flat) that unequips that slot (reuse `_unequip`), so
   the separate "Unequip X" buttons in `_equip_row` go away (keep the beast Feed/Release buttons there). Empty rows are
   not focusable.
4. Remove the text "Equipment" section from the body (the strip replaces it).
5. Gamepad: the strip's buttons join the focus chain (up/down) with the rest of the left column/close button; check
   `test_focus_audit.gd` still passes and add the strip to it if that test lists screens' focusables.

## Tests
- tests/unit/test_character_sheet*.gd (or a new test_character_sheet_gear.gd): with no gear, two rows read "No weapon",
  "No armor", none focusable; equip an iron sword (find an id in data/items.json with a `slot`): the weapon row shows its
  name and is a Button; pressing it unequips (player.equipment["weapon"] == "").
- Layout: at 1280x720 and 1280x800 the left column does not overflow the panel (reuse the steam-deck layout pattern in
  test_steam_deck_layout.gd).
