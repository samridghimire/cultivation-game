# FH-001 Newcomer hints first (systems)

## Problem
The HUD shows only `Guidance.hints(..., 1, ...)[0]` (src/ui/hud.gd:345), and `Guidance.hints` (src/core/systems/guidance.gd)
always appends the cultivation hint ("Gather N more qi...") before anything else that is not an emergency. A new player never
sees "talk to Elder Mo", "do the Headman's chores", "use your Qi Gathering Pills", "learn a technique" or "join a sect" on the HUD.
The 3 Qi Gathering Pills from the chores (450 qi, more than all of Mortal) are never mentioned anywhere.

## Change
1. In `guidance.gd` add `static func _newcomer_hints(c: CharacterData, data: GameData, flags: Dictionary) -> PackedStringArray`,
   returning, in this order and only while they apply:
   - Elder Mo: until the world flag Elder Mo's "first_steps" node sets exists. Look in data/dialogue/elder_mo.json: if the
     `first_steps` node sets no flag, add `"set_flag": "talked_elder_mo"` (or the dialogue's existing flag effect key) to that
     node's effects, and use that flag. Text: "Ask Elder Mo in Qingshi Village where to begin."
   - Usable qi items: if the player carries any item whose `use` effects include `qi` (look at how Items/Effects define a
     usable pill; `breakthrough_items` in this file is a model) and is not at a bottleneck:
     "Use your <Item name> (Inventory, I) to gather qi at once."
   - Headman chores: while the player is in Qingshi (`region_id == "qingshi"` passed in, see below) and any chore deed/dialogue
     flag the Headman sets is still unset. Find the chore flags in data/dialogue/ (grep `chore`). Text: "Headman Zhou has
     chores that pay stones and pills."
   - Technique: move the existing "Learn a technique..." line here (unchanged condition).
   - Sect: the existing `_sect_hint` result, if any, goes here.
2. Change the signature to
   `static func hints(c, data, density := 1.0, limit := 5, people := {}, flags := {}, region_id := "") -> PackedStringArray`
   (new params last with defaults, so existing callers/tests keep working). Order: emergencies (lifespan, injuries, pregnancy),
   then newcomer hints, then the cultivation hint, then the rest as today (do not duplicate the technique/sect hints).
   A player counts as a newcomer while `c.realm_index <= 1` (Mortal or Qi Refining); above that, skip `_newcomer_hints`.
3. HUD (src/ui/hud.gd:345): pass `GameState.world_flags` and `GameState.current_region`, ask for `limit` 2, and show the hints
   joined by "\n" (prefix each with "> "). Character sheet (character_sheet.gd:128): pass the flags and region too.
4. Fix the days estimate: hud.gd:345 passes the region density, but the player usually meditates at a spot with its own
   multiplier. Keep the region density but word the hint as "about N days at x<density>" only if the existing text claims a
   precise number; otherwise leave it. (Small; skip if it needs more than a few lines.)

## Tests (tests/unit/test_guidance.gd, extend the existing file if present)
- New Mortal with no flags in qingshi: hints[0] mentions Elder Mo; after setting the flag, it no longer appears.
- Carrying a Qi Gathering Pill (find its id in data/items.json) puts the "Use your ..." hint before the cultivation hint.
- At Foundation Establishment, no newcomer hints appear.
- Default-arg call `Guidance.hints(c, data)` still works (old callers).

## Acceptance
`tools/test.sh` passes; a new game's HUD shows two hint lines, the first pointing to Elder Mo.
