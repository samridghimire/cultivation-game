# GFX-078: A calendar that reads at a glance

Role: world-ui. Reference: Stardew Valley's calendar board (mechanics/layout idea only: a week grid with a weekday header and
pictures on the days). No names, story or art from it.

## Why (planner shot 2026-11-06 06:10, `screenshot_first_hour.gd -- --calendar`, 1280x800)
- The grid has 6 columns but the week has 7 days (`Calendar.DAYS_PER_WEEK`), so weekdays drift across columns and every cell
  prints a 3-letter cut of its weekday: "2 Moo", "3 Fir", "5 Woo", "6 Met", "7 Ear". "Moo"/"Woo" read as jokes.
- Cells are 150x64 and nearly empty; the only marks are 12 px icons in the top-right corner (the market glyph is barely visible).
- The detail line repeats the same market twice: "Next: Market: Travelling Market Stall (new wares each time) (Year 1, Month 1,
  Day 10); Market: Travelling Market Stall (new wares each time) (Year 1, Month 1, Day 25)".
- The village hunt (WILD-017) reuses the great-beast glyph (WILD-017 Follow-up).

## Spec (src/ui/calendar_screen.gd; no core changes except (5))
1. **7 columns.** `COLUMNS := Calendar.DAYS_PER_WEEK`. Above the grid, one header row of 7 labels with the full weekday names
   (`Calendar.weekday_label(i)`). Start the header
   at weekday 0 and put `Calendar.weekday_of(start)` empty, non-focusable spacer Controls (same size as a cell, `focus_mode =
   FOCUS_NONE`) before day 1, so each column is one weekday every month. 30 days + up to 6 spacers = at most 6 rows.
2. **Cells.** Cell size so the 7-column grid fits 1280x800 with the header, legend and detail (about 128x58; check the
   shot, also at 1280x720). A cell shows only the day number (top-left, 18 px) and below it up to 2 entry icons at 20 px
   (`ICON_PX := 20`) with the first entry's short label (12-13 px, clipped with an ellipsis, e.g. "Market", "Hunt", "Lantern
   Festival"); "+N" when there are more than 2 entries. Today keeps its gold frame; past days dimmed; marked days (WU-459's
   red seal) keep the seal. Weekday no longer appears in the cell (the header says it).
3. **Focus/gamepad.** Spacers are not focusable; arrow keys / d-pad move between real days (GridContainer neighbours work
   as long as spacers have FOCUS_NONE; if not, set `focus_neighbor_*` explicitly). Today's cell grabs focus on open;
   WU-459's mark menu and its focus return keep working. PgUp/PgDn/LB/RB month switching unchanged.
4. **Detail line.** "Next:" groups identical labels: "Next: Travelling Market Stall (new wares each time) on days 10 and 25."
   (same label within the shown month -> one phrase with the day list; different labels joined by "; "). Keep the selected
   day's own lines as they are.
5. **Hunt icon.** Give the village hunt its own glyph (a crossed spear/bow drawn in the existing icon painter or a new key in
   the calendar's icon map), not the great-beast paw. If the icon kinds live in core (VillageCalendar), add the kind there
   with a unit test.
