# WU-417: Herbs in the village book, a way in from the sheet, and fish that look different

Role: world-ui. Follow-ups of GATHER-002 (herb log) and WU-414 (village book). Reference: Immortal Life's collection pages
(one page per collection, silhouettes for what you have not found).

## What the planner saw (village_book.png 2026-10-31 12:15)
The book works, but Silver Carp and Marsh Eel have the **same orange blob icon**, so the grid tells you nothing at a
glance, and the book has no herb page although `CharacterData.herb_log` and `HerbLore.findable/log_summary` exist.

## Changes
1. `src/ui/village_book.gd`: two pages, **Fish** and **Herbs**, as tab buttons at the top (keyboard/gamepad: the tab
   buttons are focusable, `ui_focus_prev/next` or the shoulder actions InputConfig already uses for tabbed screens
   switch pages; check how the character sheet or journal does tabs and reuse it). Herbs page = the same grid built from
   `HerbLore.findable(data)` (or what GATHER-002 named it) and `player.herb_log`: found herbs framed with their count,
   unfound as dark silhouettes named "???", focus shows the description plus where it grows (the gather places whose
   gather_table lists it, with seasons if the entry has them) or the `HerbLore.missing_hint` line. Header "Herbs found:
   N of M kinds". Reuse the fish grid code: one `_build_grid(entries)` used by both pages, not a copy. Remove the
   duplicate fish scan the reviewer noted (`VillageBook.fish_order` vs `Fishing.catchable`): keep one source of truth
   in core (`Fishing.catchable`) and sort in the UI.
2. Character sheet (GFX-034's Village crafts card): an "Open village book" button under the rank bars that opens the same
   modal (through the HUD's `_add_screen` path the journal button uses, so closing returns focus to the sheet).
3. Distinct icons: `ItemIcon` currently draws one generic glyph per kind. Give `fish` items a small fish silhouette glyph
   and tint every fish/herb icon by a per-item colour: use the item's `color` field if items.json has one, else a stable
   hue from a hash of the id (same id -> same colour, saturation/value fixed so it reads on the dark slot). Do this in
   ItemIcon so the bag, shop and book all benefit.

## Tests
- Village book: Herbs page lists every findable herb; a found herb shows its count, an unfound one "???".
- Switching pages keeps a focused control (gamepad).
- ItemIcon: two different fish ids give different tints; the same id twice gives the same tint.
- The sheet's button opens the book.
