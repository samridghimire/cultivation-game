# WU-021: Look at every screen at 1280x800

**Role:** world-ui. **Why:** WU-017 found ~20 places hidden behind HUD panels only by looking at screenshots. Screens have
had ~40 additions since anyone looked at them as a whole (journal, adventures, commissions, family, milestones, sect
balance...). Layout tests check that things fit, not that they read well.

## 1. Tool: tests/sim/screenshot_screens.gd
Model it on tests/sim/screenshot_regions.gd (extends SceneTree, starts a session in `_process`, waits frames, saves PNGs
to `user://screenshots/screens/<name>.png`). Same command line (xvfb-run ... `-s res://tests/sim/screenshot_screens.gd`).

- Build a **mid-game character** so screens have content: Foundation Establishment stage 1 (set realm_index/stage the way
  tests do), a sect member with some contribution, 3-4 known techniques and a main method, ~15 inventory items (pills,
  herbs, a weapon and armor equipped, a combat talisman), married with two children (copy the spouse/children setup from
  screenshot_regions.gd), one open commission, one asked errand flag, a secret realm floor cleared, a few milestones,
  some life stats, an injury. Use real system calls where it is one line; set fields directly otherwise.
- Instance world.tscn, then for each HUD screen registered through `hud._add_screen` (character sheet, inventory,
  techniques, artifact, map, message log, clan, journal, family) plus the modal windows the HUD owns (crafting, shop,
  mission board, auction, sect balance, help, settings, pause, a ChoiceMenu for an NPC and for the sect hall, the
  encounter window with a choice encounter, the combat report after one fight): open it, wait ~6 frames, save a PNG,
  close it. Get references the way the HUD does (read hud.gd ~60-110); if a screen needs an argument (shop: a merchant
  id; crafting: a profession), pick the first valid one from data.
- Print each saved path. Must exit by itself (return true from `_process`) and never write saves.
- Add one line to docs/HANDOFF.md "Tools added" (this is the only doc you may touch besides the spec list).

## 2. Look and fix
Open every PNG (the Read tool shows images). For each screen check: text clipped or cut off at an edge, text overflowing
its panel, overlapping controls, rows so long they wrap mid-word, empty sections with a header, unreadable contrast
(dim text on dark panels), focus highlight missing on the first control.

Fix what you find in src/ui (small, local changes: wrap, clip_text, min sizes, splitting long lines, scroll containers).
Budget: ~300 changed lines. If you find more than you can fix, fix the worst and list the rest in the commit under
`Follow-ups:` with the screen name and what is wrong (the planner turns them into tasks).
