# GFX-032: A bag that looks like a bag

Role: world-ui. Reference: Immortal Life's and Wandering Sword's inventories (items read by their icon first, the
name second). Mechanics/layout ideas only.

## Why (planner shot inventory.png 2026-10-31)
The inventory is a list of plain text buttons with a 16 px icon squeezed in front ("Boar Hide  x1"), and the detail
pane on the right has no picture of the item at all. The shop screen (shop.png) has the same rows.

## What to build
1. **Item rows with framed icons** (src/ui/inventory_screen.gd `_rebuild`): each row is a button whose icon is the
   item's `ItemIcon` texture at 2x (32 px, nearest filter, `expand_icon` off; scale through an AtlasTexture-free
   `ImageTexture` resize or `TextureRect` child, your choice) inside a 36x36 slot frame (StyleBoxFlat, dark fill, 1 px
   border tinted by the item's rarity/grade if `items.json` has one, else the default border). The count is a small
   right-aligned "x3" badge, not part of the name. "(readied)" becomes a small accent tag. Row height grows to fit the
   slot; update `LIST_ROW_HEIGHT`/`list_height` and its test.
   Put the row builder in a shared static `ItemRow.make(data, item_id, count, extra_tag) -> Button` (new
   `src/ui/item_row.gd`) so the shop uses it too.
2. **A picture in the detail pane**: the selected item's icon at 4x (64 px) in a framed box left of its name, the same
   way PortraitBox frames NPC portraits (WU-408; reuse PortraitBox if it takes any texture).
3. **Shop rows** (src/ui/shop_screen.gd): Buy and Sell lists use `ItemRow.make`, with the price where the count badge
   sits ("15" with a 12 px stone icon). Keep every existing focus/gamepad behaviour: the first row grabs focus on open,
   up/down walks rows, focus_entered still selects (test_focus_audit must stay green).
4. Nothing changes for items without an icon kind: `ItemIcon` already falls back.

## Tests
- `ItemRow.make` returns a Button with a 32 px icon (or slot child), the count badge text "x3", and no count in the
  button text; with count 1 the badge is hidden.
- Inventory and shop still list the same ids in the same order (existing tests), and `list_height` matches the new
  row height.

## Acceptance
Re-render `screenshot_first_hour.gd` (inventory, shop) at 1280x800 and 1280x720 and view them: icons readable at a
glance, no clipped text, the detail pane shows the big icon. Say what you saw in the commit message.
