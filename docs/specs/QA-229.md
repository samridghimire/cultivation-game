# QA-229: Does the sect's qi bonus reach the far qi spot?

Role: systems (sim code). Reference: Tale of Immortal's sect cultivation halls (mechanics only).

## Why
QA-171 (`--activity-report`, fdfc7b4) found a far-qi sect member reaches Foundation ~264 days after a far-qi rogue
(median 1010 vs 746), the missions taking ~210 days. It also read 11.4 qi per meditation day (sect) vs 18.5 (rogue),
but that figure includes months capped at the bottleneck and injured months. In code the sect bonus is applied
everywhere: `GameState` multiplies density by `Sects.cultivation_bonus(player, data)` (game_state.gd ~3425/3440),
regardless of region. So either the sim bypasses that path, or the per-day figure is an artefact. Find out which.

## What to build (tests/sim/simulate_curious_years.gd, flag-gated)
1. `--qi-probe`: for each seed, record qi gained and days meditated only while (a) the character is not at a
   bottleneck (Cultivation.days_to_bottleneck > the block length), (b) not injured, (c) within the first 6 months.
   Print per seed: arm, region meditated in, mean density used, `Sects.cultivation_bonus`, qi/day measured, and
   qi/day expected from `Cultivation.qi_per_day(c, data, density * bonus)` at the start of the window.
2. Run `-- 10 36 --far-qi --qi-probe` (sect) and `-- 10 36 --rogue --far-qi --qi-probe`. Paste both tables in the commit.
3. Answer in the commit: does the measured sect qi/day match expected (bonus included) within 5%? If not, find where the
   sim meditates without the bonus (e.g. a direct `Cultivation.cultivate` call with region density only) and fix the
   sim if it is a sim bug. If it is a game bug (the player path loses the bonus somewhere), do not fix game code here:
   write it under `Follow-ups:` with the file and line.
4. Also answer QA-171's second question in one paragraph from the `--activity-report` numbers: missions cost ~210 days;
   what does a sect member get for them by Foundation (contribution, pills bought, stones)? Is it worth it for a player
   who only wants Foundation? Put a one-line proposal under `Follow-ups:` (the planner turns it into an owner question;
   do not change mission balance yourself).
