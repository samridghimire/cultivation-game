# WU-524: The artifact as a treasure, not a list (world-ui)

**Why (planner shot `screens/artifact.png`, 2026-11-12 12:10, 1280x720):** the Creation Artifact screen is a plain text menu.
Every sealed power is said twice ("Unseal Storage Space (100 energy) (Unsealing Storage Space needs 100 artifact energy (you
have 0).)"), the header repeats the same sealed list as plain lines, and the list scrolls off the bottom. It is the player's
golden finger and should look like a treasure.

**Reference:** Tale of Immortal's treasure panel (a header with the item's state, then its powers as cards that show
sealed/open), mechanics and layout idea only; never its names or art.

## Core helper (pure, in `src/core/systems/artifact_functions.gd`)
`static func status(c: CharacterData, data: GameData, function_id: String, flags: Dictionary) -> Dictionary` returning
`{id, name, state, cost, need}`:
- `state`: `"open"` (unsealed), `"ready"` (can unlock now), `"sealed"`.
- `cost`: the energy cost from data.
- `need`: one short phrase for what is missing when sealed, without the function's name: "100 energy (you have 0)",
  "reach Foundation Establishment", "unseal Inner World first", "" when ready or open. Build it from the same checks as the
  existing reason function (do not change that function's text: other tests use it).
Unit tests for each state and each `need` form.

## Screen (`src/ui/artifact_screen.gd`, main page only; the feed/storage/anchors/garden sub-pages stay as they are)
1. Header row: title, then **lives as pips** (filled for lives held, hollow up to `max_lives`; draw small diamonds with
   `_draw()` or a Label of ◆◇ if the font has them, check the render) and "Next life: 100 stones".
2. **Energy bar**: a ProgressBar `energy / next_cost` where next_cost is the cheapest sealed function's cost (full bar and
   "All seals broken" when none). Caption "Energy 0 / 100 (Storage Space)".
3. **Four power cards** in a 2x2 GridContainer (one per `ArtifactFunctions.KNOWN` in data order): name, a state chip
   (Open = accent, Ready = good colour, Sealed = dim), and one line: the description's first sentence when open, `need` when
   sealed, "Ready: press to unseal (100 energy)" when ready. A ready card is a focusable Button that runs the existing unseal
   action (keep its confirm step); an open card opens its sub-page (Storage, Inner World, Spirit Garden) where one exists;
   sealed cards are focusable but disabled-looking (gamepad can still read them). Remove the old "Unseal X" rows and the
   duplicated header lines.
4. Below the grid, the existing action buttons: Feed 10 / Feed 100 / Feed an item... / Lives & anchors....
5. Everything fits at 1280x720 without scrolling on the main page (test_steam_deck_layout must pass); first focus on the
   first Ready card if any, else Feed 10.
