# GFX-041: Every region grows its own trees

Role: world-ui. Reference: **Wandering Sword** (each town and wild area has its own readable silhouette: a forest reads
as a forest at a glance, a marsh as a marsh). Mechanics and approach only; all art stays drawn in code (no binary assets).

## Why (planner shots 2026-11-01, 1280x800, Spring day 1)
Every region past Qingshi uses the village's round blossom tree: Misty Forest (45 trees) reads as a sunny meadow with pink
bushes, Withered Bone Marsh has pink-blossom bushes next to bone-white rocks, and Azure Peak is a flat blue carpet with a few
blossom bushes. The only difference between regions is `tree_color`. A player who leaves the village sees the same kit
everywhere.

## What to build
1. **Tree kinds per region.** regions.json `map.decor.tree_kinds` (optional): `{kind: weight}` with kind one of
   `round` (today's tree, the default when absent), `pine`, `willow`, `dead`, `bamboo`. Document it in the regions.json
   `_doc` next to `map.decor` and validate it in `Scenery.validate` (known kinds, weights > 0, non-empty dict).
   - `Scenery.place()` picks a kind per tree from the weights using the rng it already takes (it is seeded per region, so
     the layout stays stable). Store it on the decor dict as `"tree_kind"`.
   - `Scenery.tree_look(season, seed, base, kind := "round")`: only `round` gets spring blossoms (and only when the region's
     `decor.blossoms` is not `false`; new optional bool, default true, validate as bool). `pine` and `bamboo` stay green
     all year (winter: a white cap row on pine); `willow` turns yellow in autumn and goes bare in winter; `dead` never has
     leaves (bare branches every season, grey-brown, no snow tips unless winter).
2. **Drawing** in `world.gd` `_draw_decor` / `_draw_tree` (split into `_draw_tree_<kind>` helpers so each stays short):
   - `pine`: a 3-tier stacked triangle (reuse the shape of `PixelLandmark._pine` if it reads well at decor scale), dark
     trunk, tree_color base with a lighter left edge.
   - `willow`: round crown plus 5-7 drooping 1-px strands hanging below it.
   - `dead`: the bare-branch shape `_draw_tree` uses for winter, in `8a7f6a`, plus one broken stub.
   - `bamboo`: 3-4 thin vertical stalks of different heights with node marks every 6 px and small leaf dashes at the top.
   Shadows as today. Keep everything in `_draw()` (no new nodes per tree).
3. **Forest density.** `map.decor.clusters` (optional int 0..12, validate): the number of tree clumps `Scenery.place()`
   seeds before scattering the rest; each clump puts 4-7 trees within 60 px of a centre, still honouring `is_clear` and
   the blocked rects. Misty Forest should read as woods with clearings, not as an evenly sprinkled lawn.
4. **Data** (regions.json):
   - qingshi_village: no change (round, blossoms).
   - misty_forest: `tree_kinds {"round": 3, "pine": 4, "willow": 1}`, `blossoms: false`, `clusters: 8`, trees 60.
   - fallen_star_market: `tree_kinds {"willow": 2, "round": 1}`.
   - azure_peak: `tree_kinds {"pine": 5, "bamboo": 2}`, `blossoms: false`.
   - withered_bone_marsh: `tree_kinds {"dead": 4, "willow": 2}`, `blossoms: false`, `clusters: 3`.
   - myriad_peaks_ridge: `tree_kinds {"pine": 4, "dead": 1}`, `blossoms: false`.
   - any other region with `map.decor`: pick by its look and say so in the commit.
5. If the Misty Forest mist ambient washes the canopy out (it does in the shot), lower the mist particle alpha for that
   region only if there is a per-region knob already; otherwise note it under Follow-ups.

## Tests (tests/unit/test_scenery.gd or a new test_scenery_trees.gd)
- `Scenery.place` with `tree_kinds {"pine": 1}` gives only `tree_kind == "pine"`; with no `tree_kinds` gives only `round`.
- The same region and seed give the same kinds in the same order (determinism).
- `tree_look("Spring", s, base, "pine")` has 0 blossoms; `round` with blossoms has > 0; `dead` is bare in Summer.
- `clusters: 3` puts at least 3 groups of 4+ trees within 60 px (count neighbours) and still never inside a blocked rect.
- Validation rejects an unknown kind, a weight <= 0 and `clusters: 20`.
