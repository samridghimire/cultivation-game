# ART-009: The artifact wakes as you grow (systems)

**Why (planner 2026-11-12 12:10):** the Creation Artifact is the player's golden finger (DESIGN.md pillar), yet in the first
hours it is dead weight. Its only energy source is feeding it spirit stones 1:1 (`data/artifact.json` `energy.stone_energy`)
or items, and the first seal (Storage Space) costs 100 energy while a newcomer earns ~3 stones a day and needs them for
everything else. The curious sim never unseals anything in 12 months. The mid-game screens shot (`artifact.png`) shows
"Artifact energy: 0" and four greyed seals.

**Reference:** Tale of Immortal's treasures that grow with your cultivation (a companion item that strengthens as you break
through and discover things), mechanics only, never names, story or art.

**Planner default (small, tunable in data; recorded in DESIGN.md):** the artifact also drinks from the player's own progress.
Feeding stones stays as it is.

## Data (`data/artifact.json`)
Add to `energy` (document in `_doc`, validate in `GameData._validate()`: every value a non-negative int, keys from the list below):
```json
"progress": {"stage": 15, "realm": 60, "first_win": 5, "discovery": 5, "secret_realm_floor": 10}
```
- `stage`: each minor stage gained (Cultivation stage up, not a major realm).
- `realm`: each major-realm breakthrough (Qi Refining -> Foundation etc.; also the mortal -> Qi Refining 1st Layer step).
- `first_win`: the first time the player defeats each enemy id (non-friendly fights only; spars and trial bouts don't count).
- `discovery`: each first-time discovery the game already records (grep `discover` in GameState: hidden places / sites found
  by exploring; use whatever single "first time found" hook exists, do not add a new discovery system).
- `secret_realm_floor`: each secret realm floor cleared for the first time.

With these numbers a newcomer reaches ~100 energy (Storage Space) around Qi Refining 3rd-4th layer: mortal->QR1 60 + two stages 30
+ a couple of first wins and discoveries. Check that against the curious sim's first-hour run (`tests/sim/first_hour.gd`
`--curious`, 10 seeds) and say in the commit on which median day energy first reaches 100. Aim: between day 60 and day 250.
Adjust the numbers in data (not code) if it lands far outside.

## Core (`src/core/systems/artifact_functions.gd`)
- `static func progress_energy(data: GameData, kind: String, count: int = 1) -> int` reads `energy.progress[kind]` (0 if absent).
- `static func grant_progress(c: CharacterData, data: GameData, kind: String, count: int = 1) -> int`: adds the energy,
  capped at `max_energy` like `feed`, returns the amount actually gained.
- `static func ready_to_unseal(c: CharacterData, data: GameData, flags: Dictionary) -> Array[String]`: ids of sealed
  functions whose `can_unlock` reason is "" right now (reuse the existing reason function at ~line 70-85).
- First wins need state: add `artifact_won: Dictionary` (enemy id -> true) to CharacterData `to_dict`/`from_dict` with default
  `{}` (older saves load; no SAVE_VERSION bump needed for a defaulted field, but if you bump it follow CLAUDE.md rule 5).

## GameState
Call `grant_progress` from the existing hooks (stage up / breakthrough success, the fight-won path, discovery, secret realm
floor). When the gain is > 0, do **not** post one log line per gain (log noise, LOG-001). Instead:
- Accumulate into the existing day digest / dawn fold if one fits; otherwise post at most one `progress` line per day:
  "The artifact drinks the change in you (+N energy, M in all)."
- When `ready_to_unseal` gains a new id (compare before/after), post once: "The artifact hums: Storage Space can be unsealed
  (O)." and add a Guidance hint (Next steps, priority just under the season tasks): "Unseal Storage Space in the artifact (O)".
  The hint disappears once unsealed.
