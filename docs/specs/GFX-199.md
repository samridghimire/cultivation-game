# GFX-199: Every beast its own shape

**Role:** world-ui. **Reference:** Wandering Sword's pixel beasts (look only).

GFX-196 gave wolf, boar, tiger, deer and fox their own rows (`PixelFigure.OWN_BEASTS`, pixel_figure.gd ~432), but
`DuelStage.beast_kind` (duel_stage.gd ~337, `BEAST_KEYWORDS` ~34) still maps many beasts to "" (the plain body) or to
a wrong kind. Both the fight stage and world roamers (`roamer.gd` ~262) use this, so fixing it fixes both.

## 1. Keywords (data-free, in BEAST_KEYWORDS)
`tusker` -> boar (scarred_old_tusker), `peng` -> bird (ten_thousand_li_peng, nine_thunder_peng), `porcupine` -> boar,
`bear` -> bear, `rhino` -> rhino, `tortoise`/`turtle` -> tortoise, `spider` -> spider, `basilisk`/`wyrm`/`dragonling`
-> a new `drake` kind (or snake if you run out of budget; say which). Keep longer keys before shorter ones
(`cloud_crane` before `crane`). People-like foes (puppets, ghosts, cultivators, guardians, colossi, behemoths)
stay off this list: check how `DuelStage` decides beast vs person and do not change it.

## 2. New silhouettes (24x16, same palette letters as WOLF_ROWS, two leg frames each)
- **bear:** tall rounded hump, short thick legs, small round ears, short snout.
- **rhino:** long low barrel body, a single pale horn (`p`) on the snout, thick legs, small ear.
- **tortoise:** domed shell (fur colour darkened, with 2-3 plate lines in `F`), small head forward, stubby legs.
- **spider:** low round body, eight thin legs (4 visible per side) that alternate between frames.
- **drake** (optional): snake-like neck and tail with four short legs and a ridge of `F` spikes.
Add each to `OWN_BEASTS` and `BEAST_KINDS`, and give `_beast_marks` (~494) at most a mark or two per kind.

## Tests (extend the GFX-196 silhouette tests)
- `beast_kind` for every enemy id in data/enemies.json: print the unmatched ids in the test failure message, and
  assert that ids containing bear/rhino/tortoise/spider/tusker/peng map to the expected kind.
- Each new kind's frame differs from every other kind's frame in > 40 opaque pixels and has a different bounding box
  height or width than the plain body.
