# GFX-034: A character sheet that reads at a glance

Role: world-ui. Reference: Wandering Sword's character panel (a framed portrait, short stat blocks with bars, every block titled).
Take the layout idea only: no names, art or exact layout.

## Why (planner shot character_sheet.png, 2026-10-31 06:15, 1280x800)
- Left column: the qi bar under "Mortal" is a plain `ProgressBar` with no trough, so at qi 0 there is no bar at all
  (the HUD got `UIStyle.bar` in GFX-031; the sheet did not).
- Right column: the first card has no title (identity, cultivation speed, alignment, then a blank line, then "Fishing: Novice (1)").
- The "Next steps" card indents every line after the first ("- Ask Elder Mo ..." then "  - You know ...").
- Fishing and herb lore ranks are buried as one text line; the village skills have no sense of progress.

## Changes (src/ui/character_sheet.gd, maybe src/ui/ui_style.gd)
1. `_qi_bar` = `UIStyle.bar(Vector2(0, 12), <qi colour the HUD uses>)`; keep `_qi_label` under it. At the bottleneck fill it full.
2. Spiritual root rows: build each row's bar with `UIStyle.bar(Vector2(150, 10), element colour)` so they get the same trough.
3. First right-hand card gets the title "Path" (identity, speed, alignment, sect/rogue). Do it where `split_sections` /
   `_build_cards` build the cards (a section without a heading gets "Path"), not by string-patching the text.
4. Next steps card: every hint line starts flush with the same "- " prefix (fix `next_steps_text` or the card builder);
   the "More in the Journal (J)" link stays last.
5. New card **"Village crafts"** (after Path, before Next steps), shown only when at least one skill is above 0 xp or the catch
   log is non-empty: one row per skill with the rank name, a small `UIStyle.bar` of progress to the next rank and the xp:
   - Fishing: `Fishing.rank_name(xp)`; progress to the next rank from the fishing rank thresholds (add a pure
     `Fishing.progress(xp) -> float` 0..1 in src/core/systems/fishing.gd if none exists, 1.0 at the top rank, with a unit test).
   - Herb lore: `HerbLore.rank_name(cfg, xp)` / `HerbLore.progress(cfg, xp)` (cfg = regions.json `herb_lore`).
   - Catch log: `Fishing.log_summary(c, data)` as a plain line under the fishing row.
   Remove the old one-line "Fishing: ..." / herb lore text from the first card so it is not shown twice.
6. Keep the hidden full-text source tests already read (GFX-030 kept `_text`); add the new lines there too.

## Tests (tests/unit/test_character_sheet*.gd or the existing sheet test)
- The left qi bar has a "background" stylebox override (trough) and value 0 at qi 0.
- The first card's title is "Path".
- Next steps lines all start with "- " at the same indent.
- Village crafts card absent for a fresh character with 0 xp and an empty log; present with both rows after
  `fishing_xp = 12` and `gather_xp = 20`, bars at the expected fractions.
- `Fishing.progress` at 0, mid-rank, and at/after the top rank.

Render `screenshot_first_hour.gd` (command in its header) at 1280x800 and 1280x720 and open character_sheet.png:
the qi bar trough is visible at 0 qi, every card has a title, nothing clips. Under ~300 changed lines.
