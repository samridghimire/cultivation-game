# QI-001: Deeds that raise a region's qi density

Role: systems. Size: ~150 lines. Follow-up of C-060: planting the valley guardian's seed on the Azure Peak cliffs should give a
lasting small qi-density bonus there, but qi density is a fixed number per region. C-068 (content) wires the seed to it.

## Data (data/regions.json)
- A region may carry `"qi_flags": [{"flag": String (world flag), "bonus": float (0 < bonus <= 0.5), "text": String (optional,
  why, e.g. "the guardian's seed")}]`. While the world flag is truthy the region's qi density is multiplied by (1 + bonus);
  several entries add up (1 + sum of bonuses). Document it in the regions.json `_doc` (one sentence) and validate in
  `GameData._validate()` next to the other region checks: flag non-empty, bonus in (0, 0.5].

## Exploration (src/core/systems/exploration.gd ~143)
- Change `static func qi_density(data: GameData, region_id: String, flags: Dictionary = {}) -> float`: base `qi_density`
  times `(1.0 + qi_flag_bonus(data, region_id, flags))`. The default `{}` keeps every current caller unchanged.
- `static func qi_flag_bonus(data: GameData, region_id: String, flags: Dictionary) -> float` — the summed bonus of truthy flags.
- `static func qi_flag_reasons(data: GameData, region_id: String, flags: Dictionary) -> PackedStringArray` — the `text` of
  active entries (skip empty texts), for WU-109.

## Callers to pass world flags (player-facing density only)
- `GameState.region_qi_density()` (~2109): `Exploration.qi_density(data, current_region, world_flags)`.
- `Guidance` line ~276 (`var base := Exploration.qi_density(data, region_id)`): pass `flags` if the function has them in scope;
  if not, leave it and note it in the commit.
- src/ui/hud.gd ~848 and src/ui/world_map_screen.gd ~352: pass `GameState.world_flags`.
- NPC cultivation (npcs.gd ~271, training.gd ~200) keeps the base density (world flags are the player's deeds; NPCs living
  there benefiting is fine either way, but keep the change small).

## Tests (tests/unit/test_exploration.gd or a new test_qi_flags.gd)
- No flags -> unchanged density; one truthy flag with bonus 0.1 -> x1.1; two flags -> x(1 + sum); a falsy flag (false / 0)
  -> no bonus; validation errors for bonus 0 and 0.6.
- GameState: set the flag in `world_flags` on a session in that region and `region_qi_density()` rises (use a region you add
  the entry to in a test-local copy of data, or add a real entry: Azure Peak `{"flag": "planted_guardian_seed", "bonus": 0.1,
  "text": "the valley guardian's seed"}` is what C-068 wants, so you may add that entry yourself and let C-068 set the flag).
