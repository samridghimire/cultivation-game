# WU-414: The village book (fish and herbs you have found)

Role: world-ui. Reference: Immortal Life's collection pages (a grid of everything you can catch or grow, found ones in colour,
missing ones as a silhouette with a hint). Mechanics only.

Depends on FISH-004 (on main: `CharacterData.catch_log`, `Fishing.catchable`, `Fishing.missing_hint`). The herb half
needs GATHER-002 (`CharacterData.herb_log`, `HerbLore.findable(data)`); if GATHER-002 has not landed, ship the fish page only
and leave the herb tab out (no stub).

## Screen: `src/ui/village_book.gd` (`class_name VillageBook`, a HUD modal)
- Registered with `hud._add_screen(...)` like the other modals; `open()` / `close()` / `closed` signal; grabs focus; Esc/B closes.
  No new key binding: it opens from a **"Village book"** button at the end of the journal's "Around the village" card and
  from the character sheet's Village crafts card if GFX-034 has landed (a button there too).
- Tabs (same tab style as the inventory's category tabs): **Fish** and **Herbs** (Herbs only with GATHER-002).
- Each tab: a header line (`Fishing.log_summary` / the herb equivalent) and a grid (GridContainer, 6 columns at 1280 wide,
  5 at 1280x720 if needed) of framed slots built with GFX-032's `ItemRow`/`ItemIcon` framing:
  - found: the item icon at 2x, the name under it, a count badge (caught N);
  - not found: the same icon drawn as a dark silhouette (modulate ~ Color(0.1, 0.1, 0.12)) and "???" as the name.
- Focusing a slot (keyboard/gamepad navigation through the grid; every slot is a focusable Button) fills a detail line at the
  bottom: found -> the item's description and where it bites/grows ("Bites at Village Pond Jetty; more in rain");
  not found -> a hint: where and when it can be found if the player has been to that region (use `Fishing.missing_hint` style
  wording, a static helper is fine: `VillageBook.hint_for(item_id, data, c) -> String`), else "Somewhere you have not been."
- Order: by region (start region first, the order of regions.json), then by item price ascending.

## Tests (tests/unit/test_village_book.gd)
- The fish grid has one slot per `Fishing.catchable(data)` entry; found vs silhouette follows `catch_log`.
- `hint_for` for a caught, an uncaught-in-a-visited-region and an unvisited-region fish.
- open() grabs focus on the first slot; close() emits `closed`; the journal button opens it.
- Herb tab present only when the herb log exists.
