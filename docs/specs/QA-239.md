# QA-239: Tests that survive a new villager

Role: qa. Reference: none (tooling).

## Why
C-403 (21095eb) tried to add one named mortal to Qingshi (a pond fisher, `activity: fish`, `spots.work` on the Village Pond
Jetty). Adding **any** new named Qingshi NPC to data/npcs.json (middle or end of the file) broke unrelated seeded tests:
- `tests/unit/test_clean_first_frame.gd` (the He Ying label moved),
- `tests/unit/test_first_hour_guard.gd` (only 1 of 5 newcomers reach QR1 in 30 days),
- `tests/unit/test_foundation_year.gd` (odds count),
- at the list end: `tests/unit/test_season_banner.gd`, `tests/unit/test_season_card.gd`.
Content can't grow while one villager reshuffles the whole world's RNG stream and the first-frame layout.

## What to do
1. Reproduce: add a throwaway named Qingshi NPC (copy an existing mortal's shape: festival_lines, spots, a like, two scenes at
   favor 40/60) and run those five tests. Record which ones fail and why.
2. For each, find the coupling and fix the **cause**, not the expected numbers:
   - RNG coupling (likely): world setup draws per-NPC from the shared `GameState.rng`, so one extra NPC shifts every later
     draw. Where a system rolls per NPC (schedules, families, likes, spots...), derive a per-NPC RNG
     (`seed = hash(npc_id) ^ world_seed`, a local `RandomNumberGenerator`) so adding an NPC leaves other NPCs' rolls alone.
     Keep CLAUDE.md rule 4 (no global randf). Note any save impact (there should be none if the seed is derived).
   - Layout coupling (first frame label): if the test asserts a specific label position, assert the property it guards
     (no overlap / on screen) instead.
   - A test whose pass hinges on a lucky seed (1 of 5 newcomers reach QR1): if after the RNG fix it is still fragile, report
     the real rates over 20 seeds in the commit message and set the threshold from those, with a comment.
3. Add `tests/unit/test_npc_addition_stable.gd`: build the world with the data as-is, then with one extra synthetic named NPC
   injected into `data.npcs` (in code, not JSON), and assert that the other NPCs' seeded attributes you decoupled (e.g. their
   spots/schedules/likes) are identical.
4. Leave the throwaway NPC out of the commit. C-405 adds the real fisher afterwards.

## Acceptance
- With a throwaway named Qingshi NPC added, all five tests pass (say so in the commit message, then remove it).
- tools/test.sh prints ALL CHECKS PASSED. If world-gen numbers move, run `tools/balance.sh --check` and refresh the sections
  the RNG change explains.
