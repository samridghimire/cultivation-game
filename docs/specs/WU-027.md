# WU-027: Option descriptions in ChoiceMenu; reasons out of labels (world-ui)

**Why:** WU-022 added a description line under ChoiceMenu that shows the focused option's `reason`, but most
interactables still glue the reason onto the label ("Court Mei Ling (needs favor 40)") and leave `reason` empty, so the
line is blank and labels get long enough to clip at 1280x800 (reviewer notes, WU-018, WU-021). We also want room for
a description on *enabled* options (WU-029 meditation preview, WU-030 explore outlook).

## ChoiceMenu (src/ui/choice_menu.gd)
- Options may carry `"description": String`. The line under the buttons shows, for the focused/hovered option:
  `reason` when the option is disabled and has one, else `description`, else "". Disabled options keep the reason in
  the warning color (UIStyle.CATEGORY_COLORS["warning"]) and descriptions use the current grey.
- Document both keys in the `Interactable.get_options()` doc comment (src/world/interactables/interactable.gd).

## Interactables: move the reason out of the label
For each of these, stop appending " (%s)" / " [%s]" with the reason to the label and pass it as `"reason"` instead
(keep it in the label only where the label would otherwise be ambiguous, e.g. nothing):
- src/world/interactables/npc.gd ~340 (choice reasons)
- src/world/interactables/deed_giver.gd ~21
- src/world/interactables/sect_hall.gd ~24
- src/world/interactables/meditation_spot.gd: `_contemplation_options`, `_temper_option`, `_dual_cultivation_options`
- src/world/interactables/secret_realm_entrance.gd ~47 (drop the " [reason]" suffix; `reason` is already set)
- src/world/interactables/inheritance_grounds.gd (same check)
- Any other `label += " (%s)" % reason` in src/world/interactables (grep for it).
Keep cost/duration notes that are not reasons ("(1 month)", "(50 stones)") in the label.

## Tests
- tests/unit/test_choice_menu.gd (or the closest existing ChoiceMenu test): focusing a disabled option shows its reason;
  focusing an enabled option with a `description` shows it; an option with neither clears the line.
- A test that walks every region's interactables (reuse test_interactable_fuzz.gd's setup if it exposes one) and asserts
  no option label contains its own `reason` text and no label is longer than 90 characters (if some unavoidable labels are
  longer, raise the limit and list them in the commit).
- test_focus_audit.gd still passes.
