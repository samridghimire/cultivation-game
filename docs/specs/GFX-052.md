# GFX-052: Labels you can read on any ground

Role: world-ui. Reference: Wandering Sword's map labels (a name always reads, near or far; mechanics/look only, no assets).

## Problem (planner shots 2026-11-02 00:15, `--region=` at 1280x800; QA-187 Follow-ups)
- Place labels away from the player fade (`Interactable._draw_label`: `fade = minf(label_fade, PLACE_FAR_ALPHA)` when covered,
  plus the distance fade in `label_fade`). The fade multiplies **both** the fill and the outline alpha, so a far label is
  pale grey text with a faint outline. On grass it is just readable; on Fallen Star Market's paved ground (`paved`), Azure Peak
  and Myriad Peaks Ridge (`scree`) it vanishes: "Hall of Gentle Hands Clinic", "Hunters' Bounty Board", "Sect Envoy Hall",
  "Artisan Quarter", "Crystal Vein", "Hermit Forge", "Cloud-Stream Ford", "Sundered Peak Trail", "Ridge Hermit's Stall",
  roamer labels like "Iron-Brick Boar (Deadly)" are unreadable.
- Labels of places at the map edge are cut by the screen: "Shadow Curio Den" (market, left edge), "Vermilion Script
  Talisman Stall" (right edge), "Spirit Spring (2x qi)" (Qingshi, top right). `clamp_label_left` clamps to the view rect, but
  the shots show it is not enough when the place itself is half off-screen (check whether the clamp runs before the camera
  settles, or whether the label layer's view rect differs from the real viewport).
- Azure Peak: "Ancient Cave" and "Bandit Camp" labels overlap each other at the bottom right.

## Change
1. `src/world/interactables/interactable.gd` `_draw_label()` (and roamer labels in `roamer.gd` if they draw their own):
   - Far/covered labels fade the **fill colour toward a muted tone** (lerp toward `Color(0.78, 0.78, 0.74)`) but keep
     `alpha >= 0.85`; the outline stays `Color(0, 0, 0, 0.85)` at size 4 regardless of fade. Only a label hidden on purpose
     (fade 0, e.g. a modal open) disappears.
   - On ground styles `paved` and `scree` (the region's `map.ground_style`, reach it the way world.gd passes region data
     to interactables, or a static `Interactable.ground_style` set by world.gd when the region builds) draw a soft plate
     behind each label: `draw_rect` of the text rect grown by 3 px, `Color(0.05, 0.05, 0.07, 0.45 * fade)`, before the
     outline. Grass/litter/bog keep no plate (they read fine now).
2. Edge clipping: make every label (place, NPC, roamer) lie fully inside the visible viewport rect, re-clamped when the
   camera moves (the label layer already redraws on label layout passes; make sure the clamp uses the camera's current
   visible rect in label-layer coordinates). Keep the existing `clamp_labels`/`clamp_label_left` helpers, fix their input.
3. Overlap: if two labels still overlap after `LabelLayout.resolve` (e.g. Ancient Cave / Bandit Camp), the lower-ranked one
   fades to the far style (not hidden). Check that both places are in the ranked list (abode/explore/inheritance places).

## Tests
- Unit (`tests/unit/test_label_layout.gd` or a new `test_label_readability.gd`): a pure helper
  `Interactable.label_paint(fade: float, covered: bool) -> Dictionary` returning `{fill: Color, outline: Color}`; assert the
  fill alpha >= 0.85 and outline alpha == 0.85 for any fade in (0, 1], and fill alpha 0 at fade 0.
- `clamp_label_left` tests for a label wider than the space to the right edge and to the left edge (already partly tested:
  extend).
