# GFX-007: a pixel-style placeholder ground until the pack lands

The owner finds the code-drawn art too basic (DESIGN.md "Art direction"). Real pack art waits on GFX-002 (the owner must
commit a pack), but the biggest flat area on screen, the ground, can already read as pixel-art terrain: a generated
16x16 tile with a few shades and speckles instead of one flat colour. This is a **fallback**: it is used only when no
`ground_*`/`path_*` sprite is mapped (GFX-006), so the pack replaces it with no code change. Generated in code, so there
is no licence question and no binary file is committed. Reference: Wandering Sword's grass and dirt tiles (look only).

Depends on GFX-006 (the ground/path tiling hooks). If GFX-006 is not on main yet, take another task.

## Files
- `src/world/ground_tiles.gd` (new), `class_name GroundTiles extends RefCounted`, `##` doc comment, all static, pure
  except for creating `Image`/`ImageTexture`:
  - `static func make_tile(base: Color, seed_text: String, kind: String) -> ImageTexture`: a 16x16 `Image.FORMAT_RGBA8`.
    Fill with `base`; then, with a local `RandomNumberGenerator` seeded from `hash(seed_text + kind)` (deterministic; never
    the global rng), sprinkle ~14% of pixels `base.darkened(0.12)`, ~6% `base.lightened(0.10)`, and for `kind == "ground"`
    2-3 tiny 2-pixel grass blades (`base.lightened(0.18)`, vertical pairs). For `kind == "path"`: ~18% darker pebbles,
    no blades. Make the tile seamless by construction (only single-pixel features that never cross the edge, or wrap
    coordinates with `% 16`).
  - `static func cached(base: Color, seed_text: String, kind: String) -> ImageTexture`: memoised by
    `"%s|%s|%s" % [base.to_html(), seed_text, kind]` in a `static var` Dictionary (a region redraw must not rebuild it).
  - `static func edge_color(base: Color) -> Color`: `base.darkened(0.25)` (used for path borders).
- `src/world/world.gd` `_draw()`: when GFX-006's `Sprites.first(["ground_<id>", "ground"])` is null, tile
  `GroundTiles.cached(Color(map.ground), region_id, "ground")` the same way (same loop, `Sprites.scale()`); same for paths
  with `map.path_color` and `"path"`, and draw a 2 px `edge_color` line along each path rect's outline (inside the rect)
  so paths have a border. Keep the map border rect.
- Settings: none. The CanvasModulate season tint (world.gd `_build_season_tint`) already tints the whole canvas; check a
  winter shot still reads.

## Edge cases
- `map.ground` missing: today's default `4d6b3c`.
- Nearest filtering: `project.godot` has `default_texture_filter=0`; draw with integer scale so speckles stay square.
- Performance: one texture per region and kind; the tiling loop runs only on redraw (see GFX-006's note).

## Tests (tests/unit/test_ground_tiles.gd)
- `make_tile` returns a 16x16 texture; two calls with the same arguments give identical images (compare `get_image().get_data()`).
- Different `seed_text` gives a different image; the share of pixels equal to `base` is between 60% and 90%.
- `cached` returns the same object for the same key.
- Seamless: for a "ground" tile, no blade pixel sits in column 15 or row 15 that continues off the edge (or test the
  wrap rule you implemented).
