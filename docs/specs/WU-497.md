# WU-497: A character creation screen you want to look at

Role: world-ui. Reference: Tale of Immortal's and The Scroll of Taiwu's birth screens (mechanics only: show the new
character's face and fate at a glance, reroll to see it change; never their names, layout or art).

## Problem (planner shot 2026-11-09, `creation.png`)
"A New Life" is a text panel: two unlabeled name boxes, a sex drop-down, the root as one yellow line, the talent as one
line, five attributes as grey paragraphs, and Reroll/Begin/Back. The player cannot see who they are making, and the
root and attributes (the most important roll in the game) read like a tooltip.

## Build (src/ui/character_creation.gd, keep it under ~250 changed lines)
1. **Two columns** inside the existing framed panel (widen to ~860 px, still fits 1280x720):
   - Left (~260 px): a framed portrait, `PixelFigure.frame(look, "down", 0)` at 6x with nearest filter in the same frame
     the character sheet / family screen use (grep WU-493's portrait helper in family_screen.gd and reuse it, move it to
     a shared static if needed). The look comes from the rolled character the way the world builds the player's look
     (sex, hair, robe colour for a mortal); it updates on sex change and on reroll. Under it, labelled fields:
     "Surname" and "Given name" (Label above each LineEdit) and the sex selector.
   - Right: **Spiritual root** as one row per element the root has: an element colour swatch (reuse the element colours
     already used by the character sheet / world map pips; grep `element_color`), the element name, and a bar 0-100 for
     purity with the number. Root kind in the heading ("Mixed Root"). **Talent** as a coloured badge (the existing
     `talent_verdict` word and colour) plus the multiplier and the "(average is 1.0x)" note in dim text.
   - **Attributes** as five rows: name, value, a short bar (scale to the attribute's data max, or 20 if none), and the
     existing description as the row's tooltip plus a one-line dim summary (first clause only, e.g. "Extends lifespan;
     Blacksmiths") so nothing wraps to two lines.
2. **Reroll feel:** on Reroll, the bars animate from 0 to their value over 0.25 s (Tween) and the portrait does a 1-frame
   flash (modulate); skip the animation when reduced motion is on, if that setting exists.
3. Buttons unchanged in meaning (Reroll Fate, Begin, Back), focus starts on Reroll as today; the focus path reaches the
   name fields and sex selector by keyboard and gamepad (`focus_neighbor_*` or container order). FH-013 rerolls stay free.
4. Nothing in core changes; the rolled values come from the same calls as today.

## Tests (tests/unit/test_character_creation.gd)
- After `_roll()`, the root rows count equals the number of elements in the rolled `spiritual_roots`, and each bar value
  equals that element's purity.
- Changing sex rebuilds the portrait texture (a different texture instance) and the given-name field keeps its text.
- Five attribute rows exist and each has a non-empty tooltip.
- Focus: Reroll has focus after `_ready`; Begin and Back are reachable with `ui_right`/`ui_down` neighbours.

## Acceptance
Render `screenshot_screens.gd -- --creation` at 1280x800 and 1280x720 and view them: portrait visible, nothing wraps or
runs out of the panel, the root bars and talent badge readable. `tools/test.sh` prints ALL CHECKS PASSED.
