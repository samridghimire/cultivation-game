# GFX-102: Gather sites look like what they are

Role: world-ui. Reference: Wandering Sword's readable resource spots (mechanics only: each spot's look tells you what you'll find).

## Why
Planner shots 2026-11-08 12:10 (`--region=` all five): every gather site draws the same `_gather()` picture (a dirt oval with
seven sprouts, `src/world/pixel_place.gd:510`). "Old Quarry Tailings" (ore), "Meteor Crater Field" (fire crystals, star silver),
"Crystal Vein", "Frost Ledge", "Corpse-Lily Bog" and "Cloud-Sea Orchid Terraces" all look like a vegetable bed.
GFX-095 fixed the same problem for explore sites; copy its pattern exactly.

## Build
1. `src/core/systems/place_looks.gd`: `const GATHER_LOOKS := ["patch", "rubble", "crater", "crystal", "frost", "terrace", "bog"]`.
2. `data/regions.json`: optional `look` on `type: "gather"` places (default `"patch"`). Document it in the regions `_doc`
   next to GFX-095's explore `look`; validate in `GameData._validate()` like the explore look (game_data.gd ~645) using
   `PlaceLooks.GATHER_LOOKS`. Set:
   - Village Herb Slope, Herb Patch: `patch` (unchanged picture)
   - Old Quarry Tailings: `rubble` (grey stone chips and two broken blocks, one rusty ore glint)
   - Meteor Crater Field: `crater` (scorched dark ring, a cracked black rock centre, 2-3 red/orange ember glints)
   - Crystal Vein: `crystal` (a rock outcrop with 3-4 pale-blue crystal spikes)
   - Frost Ledge: `frost` (a white-blue rock shelf with snow and two tiny blue flowers)
   - Cloud-Sea Orchid Terraces, Thunder-Struck Terraces: `terrace` (2-3 stepped green bands with stone edges and orchid dots)
   - Corpse-Lily Bog: `bog` (dark murky water pool, reeds at the rim, two pale lilies)
3. `src/world/pixel_place.gd`: one `_gather_<look>()` builder per look, same canvas size as `_gather()` (50x34) so place rects
   and labels don't move; the art-kind switch picks `gather_<look>` the way explore picks `explore_<look>` (see how the
   world sets `art_kind` from `look` for explore, GFX-095, and do the same in the gather interactable).
   Keep the seasonal tint/snow cap logic that `_gather()` gets today. Keep the `Sprites` hook keys working (a `gather`
   sprite still overrides every look; add `gather_<look>` keys as optional overrides).
4. `place_art.gd`: nothing changes unless it lists art kinds explicitly; if it does, add the new ones.

## Tests
- GameData rejects an unknown gather look (bad fixture) and accepts each listed one.
- Every gather place in regions.json has a look in GATHER_LOOKS (or none).
- PixelPlace builds a non-empty canvas for every `gather_<look>` of the same size as `_gather()`.
