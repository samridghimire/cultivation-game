# GFX-059: A world map you can read

Role: world-ui. Reference: Tale of Immortal's and Wandering Sword's world maps (a painted land with named
places on it, roads between them, icons beside each name). Mechanics and layout only; no names, story or art.

## What is wrong (planner shot 2026-11-02 12:15, `screenshot_screens.gd -- --map-shot`, map_market_1280x800.png)
- `withered_bone_marsh` has **no `map_pos`** in data/regions.json, so `WorldMapScreen.layout()` puts it on the
  fallback circle at (0.5, 0.12), on top of Myriad Peaks Ridge (0.66, 0.2): the two node boxes and their
  "Unexplored" lines overlap, and the 14d route line runs through both labels.
- Names are cut: NODE_SIZE is a fixed 132x40, so "Fallen Star Mark", "Withered Bone Mars" are clipped.
- The canvas (CANVAS_SIZE 560x420) is a dark flat rectangle; the map has no land, only lines. Route day labels
  ("14d", "7d", "10d") sit on top of node boxes.
- The forage leaf (WU-433), coin and paw glyphs are 12 px specks drawn over the box corner; the mark dots under a
  node are 5 px circles without meaning on their own.

## Spec
1. **Data**: give withered_bone_marsh a `map_pos` (south-west of Myriad Peaks, east of Misty Forest, e.g. [0.72, 0.55]:
   the marsh lies between the forest and the market in the route table: misty 6d, market 9d, ridge 14d). Re-place the
   others if needed so every pair of node centres is at least 0.18 apart in x or 0.14 in y. Add a data test in
   tests/unit/ (e.g. test_world_map_layout.gd): every region has `map_pos`; no two node rects (computed by the same
   helper the screen uses, see 2) overlap at the screen's canvas size.
2. **Node size from the name**: `static func node_rect(name: String, center: Vector2, font: Font, font_size: int) -> Rect2`
   (width = text width + 24, min 110; height 40). Drawing and the overlap test use it. The full region name always shows.
   If the canvas is too narrow at 1280x800, grow CANVAS_SIZE (e.g. 640x460) and shrink the details column, keeping the
   whole window inside 1280x720 (check `screenshot_screens.gd --map-shot` at both sizes).
3. **Route day labels**: place each label at the route midpoint, offset perpendicular to the line by 10 px, with a small
   dark backing rect (UIStyle colours); if the label rect hits a node rect, slide it along the line (0.35 / 0.65 of the
   way) until it does not. A pure static helper `route_label_pos(a, b, label_size, node_rects) -> Vector2` with a unit test.
4. **A painted land** (code-drawn, no binary assets): in `_draw_map()` before the routes, fill the canvas with a muted
   parchment/land colour and draw, from region data only: for each region a soft blob in a colour picked by its
   `map.ground_style` / `ground` colour (grass green, scree grey, bog olive, paved tan), radius ~70 px, low alpha;
   a few mountain glyphs (simple triangles with a snow cap) around regions whose ground_style is scree; small tree glyphs
   around misty_forest-like grass regions with many trees (`map.decor.trees` >= 30). Deterministic (seeded by region id),
   cheap (drawn once into the canvas; it redraws only on `queue_redraw`).
5. **Glyph row**: draw the weather/coin/paw/leaf glyphs as a row **below** the node box (not on its corner) at 2x scale
   (24 px), left to right: weather, coin (open market), paw (gold for a great beast), leaf (forage). Keep the colour dots
   for marks (region_marks) but move them to the row too, after the glyphs. The legend (if the screen shows one) matches.
6. Gamepad focus and the details pane behave as before (`_focus_selected`, `_select`).

## Tests
- test_world_map_layout.gd: every region has map_pos; node rects from `node_rect` do not overlap; `route_label_pos`
  returns a position whose rect hits no node rect for the shipped data.
- Existing world map tests stay green (forage_line, hint_note, region_marks, ...).

## Acceptance
Render `tools/godot.sh ... -s res://tests/sim/screenshot_screens.gd -- --map-shot` (xvfb, 1280x800 and 1280x720) and
**view** the shots: six full names, no overlapping boxes or labels, a land under the roads, glyphs readable. Say in the
commit which shots you viewed. Under ~400 changed lines; no balance run (UI only).
