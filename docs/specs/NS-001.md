# NS-001 Nascent Soul content pack, part 1 (content)

## Problem
All combat content stops at Core Formation: 0 enemies and 0 encounters at Nascent Soul or above, the top secret realm caps at
Nascent Soul, and a sensible player reaches Nascent Soul by age ~36. After that, exploring yields nothing new.

## Change (data only)
1. data/enemies.json: 8 Nascent Soul enemies spread over stages 0-3 (Early/Middle/Late/Peak): at least 3 beasts (dropping
   high-grade herbs/ores already in items.json, or none), 2 righteous/neutral cultivators (one non-lethal sect enforcer), 2
   demonic cultivators, 1 ancient construct or ghost. Fill `realm_training` for the nascent_soul realm index if it is missing:
   follow the curve of the existing entries (each realm roughly +3 attack/+3-4 defense/+12 hp in the existing list is the
   pattern up to Core; extend it, don't invent a new formula), and read the `_doc` for how it is applied.
2. data/encounters.json: 15 encounters with `min_realm: "nascent_soul"` across the existing high regions' encounter_tags
   (azure_peak, withered bone marsh, fallen star market): 8 fights, 4 choice encounters with righteous/neutral/demonic options
   (use existing effect keys only), 3 fortunes (dao insight, rare herb, a method manual already in the data if one fits).
   Set `blocked_by_flag` on every choice as the existing choice encounters do.
3. Balance: run `tools/godot.sh --headless --path . -s res://tests/sim/simulate_combat.gd` and make each new enemy hit the
   QA-007 target: a typical player at the enemy's own realm and stage wins 60-85%, near 0% a full realm below. Paste the before/
   after table rows for the new enemies into the commit message. If the sim's "typical" profile has no Nascent Soul gear or
   techniques and every result is 0% or 100%, note that under Follow-ups (QA will extend the sim) and tune against the
   `realm_training` curve instead.

## Tests
- Data validation, test_data_references and test_combat_balance (guard: no forced fight is unbeatable) must pass.

## Acceptance
`tools/test.sh` passes; exploring Azure Peak at Nascent Soul can roll the new encounters.
