# WU-533: "For you" means for you (world-ui, fix of WU-532)

Reference: Stardew Valley's and Immortal Life's shops, which put the one thing you came for on top and leave the rest in
plain order (mechanics only).

## What is wrong (planner shots 2026-11-13 12:10, 1280x720)
- `first_hour/shop.png` (fresh mortal, Wandering Merchant, spring): **every** row is tagged "(for you)": Candied Haws, Sweet
  Rice Ball, Ginger Sugar Soup, Green Dumpling, Qingming Cake, Willow Branch, Zongzi, Moon Cake. `Items.useful_now`
  (src/core/systems/items.gd:283) returns true for any usable item that `Effects.check` allows, so every snack and festival
  food counts as a "pill your realm accepts". The tag means nothing, and the Iron Fist manual the HUD hint names
  ("No fighting style: Iron Fist") is not on top.
- With `--season=Winter`, the list starts with untagged Candied Haws while Zongzi and Moon Cake further down carry the tag:
  the "All" tab's order does not follow `Items.shop_order` in every case. Find out why (category grouping? the seasonal
  re-sort?) and make the All tab use `shop_order`.
- `screens/shop.png` (Everything Stall): the footer says "No weapons or armor here. The Heavenforge Smithy ... sells them."
  while the list shows an Iron Sword and four armours. The footer (Guidance, src/core/systems/guidance.gd ~1573-1603) must
  only show when this merchant's stock has no `equip` item.
- The same rows read "Iron Sword (upgrade)  (for you)": two tags for one fact.

## Changes
1. `Items.useful_now(c, data, item_id) -> bool`, pill branch only. A usable non-equip, non-manual item is useful now when
   ANY of:
   - it is a breakthrough aid the player's current realm/stage accepts (an effect key the breakthrough code reads; look
     at how Guidance picks its "buy a breakthrough pill" hint and reuse that test, do not duplicate a list);
   - it heals and the player is hurt (hp below max) or has an injury it treats;
   - its `qi` effect is at least 10% of the qi the player still needs for the current stage (so Qi Gathering Pill's 150
     qi counts for a mortal needing 300, an 8-qi Candied Haws does not).
   Snacks, festival foods, charms and buffs are never "for you" by this branch.
2. Cap the tag: at most 4 rows carry "(for you)" (the first 4 after the hinted item, in `shop_order` order). Keep the
   ordering of the rest unchanged.
3. Hinted item first: when the HUD's first hint names a technique ("No fighting style: Iron Fist"), the hinted item is the
   manual that teaches it, if this merchant sells it. Check how the shop screen gets `hinted` today and fix the mapping.
4. The All tab (and every category tab) lists rows in `Items.shop_order` order.
5. One tag per row: when a row is "for you" because it is an upgrade, show "(upgrade, for you)" — or just "(for you)" with
   the upgrade arrow in the detail panel. Pick one, keep it short.
6. Footer: the "No weapons or armor here" line shows only when no item in this merchant's current stock has `equip`.

Files: src/core/systems/items.gd, src/ui/shop_screen.gd (or wherever the Buy tab is built; grep "(for you)"),
src/core/systems/guidance.gd (footer condition), tests.

## Tests (tests/unit/test_items.gd or a new test_shop_order.gd)
- A fresh mortal: candied_haws, zongzi, moon_cake, willow_branch are NOT useful_now; qi_gathering_pill IS.
- A hurt character: a healing pill is useful_now; at full hp it is not.

- shop_order with hinted = the Iron Fist manual id puts it first.
