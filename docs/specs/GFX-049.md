# GFX-049: Jetties that stay off the road, beasts' trees without black holes, finds you can see

Reference: Wandering Sword's docks and readable pickups (mechanics of readability only; no art, layouts or names).
Role: world-ui. Size target: under ~350 changed lines.

## What the planner saw (2026-11-01 18:15, `screenshot_first_hour.gd -- --region=<id>`, 1280x800)
1. **Misty Forest:** the Misty Pond Jetty runs from the pond's bottom rim straight down **across the main east-west road**
   (pond ~860,280; road y ~375-420; jetty ends ~y 415). A jetty must never cross a path.
2. **Vertical jetties** (Qingshi Village Pond Jetty, Withered Bone Marsh Bog Pond Shore, Misty Forest) read as a thin pole
   with a ladder, not a walkway: GFX-046 reuses the horizontal texture rotated 90 degrees, and it is about 10 px wide.
3. **Withered Bone Marsh:** every dead tree sits on a dark round blot (looks like a hole in the ground), about 30 px across.
4. **Forage pickups (WU-427)** are 3-5 px specks: green sprigs on grass and red dots on the bog are almost invisible
   without the 3 s sparkle. A new player will not notice them.

## Changes
### A. Jetties never cross a path (src/core/systems/scenery.gd `jetty_layout`)
- After computing `rect`, clip it against every `map.paths` rect: shorten the jetty so its far end stops 6 px before
  the first path it would enter (keep the rim end). If the clipped length is under 28 px, try the other axis (a
  horizontal jetty from the nearest side rim, same rules); if that also fails, keep the clipped one but at least 28 px
  long (overlapping the water more).
- Return the final rect as today (`{rect, vertical, on_water}`); `landmark_rects` already uses it.
- Unit tests (tests/unit/test_scenery*.gd or a new file): a synthetic region with a pond and a path 20 px below the rim:
  the jetty ends >= 6 px above the path; a real-data test: for every region, no jetty rect intersects a path rect.

### B. A real vertical jetty (world drawing, wherever GFX-045/046 draw the `jetty` landmark)
- Draw vertical jetties with their own pattern instead of a rotated horizontal one: planks run **across** (horizontal
  boards 3 px tall with 1 px dark gaps), two darker side rails, two pairs of posts showing in the water at the pond end.
- Width: at least 18 px (use `short_side`, clamped to >= 18); same palette as the horizontal jetty, winter snow cap rule
  kept (GFX-043).

### C. No black blots under marsh trees (world.gd `_draw_tree_bare` and its shadow)
- Replace the round dark shadow under dead/bare trees with a flat ellipse at the trunk foot: width ~1.2x the trunk
  spread, height ~0.3x the width, alpha 0.22, colour the region's ground shade darkened (not near-black).
- Living trees keep their current shadow unless it shares the same code path; then give them the same ellipse rule.

### D. Finds you can see (src/world/interactables/forage_pickup.gd)
- Draw each pickup at 2x its current pixel size (nearest filter, integer scale), with a 1 px dark outline already in the
  texture or added when built.
- Under it, a soft pale ground disc (ellipse ~20x8 px, colour `Color(1, 0.95, 0.7, 0.28)`), so it reads on grass and bog.
- Keep the sparkle; with `reduce_motion` the disc stays, the sparkle is drawn static (as today).
- Pickups still keep their 40 px spacing and stay off paths/places (WU-427 rules).
