# GFX-145: A ridge that climbs

Role: world-ui. Reference: Wandering Sword's mountain maps (look only: broken rock bands, scree, mist that pools).

## What the planner saw (2026-11-14 18:10, 1280x720, `--region=myriad_peaks_ridge` default season and `--season=Winter --region=azure_peak`)
Myriad Peaks Ridge reads as a dark car park: flat grey ground, rectangular grey slabs with a white top strip ("ledges"),
stacks of grey circles ("boulders" look like bubbles), and the cloud wisps are straight white bars. The Thunder-Struck
Terraces are a green box. Lan Zhiyuan's name sits on top of the "Skyfall Thunder Pavilion" label.

## Build (src/world/world.gd `_draw_relief` ~1691, src/core/systems/scenery.gd `relief_layout` ~1053, src/world/cloud_wisps.gd)
1. **Ledges -> rock bands.** Drop `draw_rect(r, ..., false, px)` (the box outline) and the two winter `draw_rect` snow
   strips. Draw each ledge as a jagged top polygon (already `Scenery.jagged_outline`) whose bottom edge is also ragged and
   2-3 stepped strata (lighter top face 30% of the height, darker cliff face below, a 1-2 px dark crack line between
   strata). Winter/high snow: a snow cap polygon that follows the jagged top outline (offset 2-3 px down), not a rect,
   with 1-3 snow pockets on the face. Ends taper (first/last 15% of the width narrower) so no ledge ends in a vertical cut.
2. **Boulders -> rocks.** Replace the 4 concentric circles with a seeded irregular polygon per rock (6-9 points, radius
   jitter 0.75-1.0), a 1-px darker outline, one lighter facet polygon top-left, a contact shadow polygon offset (1, 2) px.
   Keep sizes and counts.
3. **Scree ground.** For `map.ground_style == "scree"`, add sparse pebble clusters (2-4 px light/dark dots in groups of
   3-6, ~1 cluster per 64x64 px, seeded by region id) and 2-4 faint lighter "slope" bands per map, drawn under decor.
   Must not touch paths or place rects (reuse the keepout the decor scatter uses).
4. **Wisps.** In cloud_wisps.gd draw each wisp as 3-5 overlapping soft ellipses of falling alpha (no hard rect edge),
   width 80-160 px; keep the drift.
5. **Labels.** Check `LabelLayout` places the NPC name below/aside when it would overlap a place label (Lan Zhiyuan vs
   Skyfall Thunder Pavilion); if the rule exists but misses this case, fix the overlap test (rects must not intersect,
   with 2 px margin).
6. The Thunder-Struck Terraces / Cloud-Sea Orchid Terraces box look is GFX-147, not this task.

## Tests (tests/unit, pure parts only)
- `Scenery.relief_layout` unchanged for counts (existing tests keep passing).
- a new pure helper `Scenery.rock_polygon(center: Vector2, radius: float, seed: int) -> PackedVector2Array`: 6-9 points,
  every point within [0.75, 1.0] x radius, deterministic by seed.
- a new pure helper `Scenery.scree_clusters(region: Dictionary, keepouts: Array[Rect2]) -> Array[Dictionary]`: no cluster
  centre inside a path or place rect; same output for the same region.
- the label layout case: two rects as in the shot no longer overlap.
