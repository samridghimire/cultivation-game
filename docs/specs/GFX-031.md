# GFX-031: The HUD at a glance

Role: world-ui. Reference: Wandering Sword's corner HUD (a framed portrait-less status block where bars and small
icons carry the numbers). Mechanics/layout ideas only, no art or layout copied.

## Why (planner shots 2026-10-31, hud_arrival.png / field.png at 1280x800)
The top-left status card is the first thing a new player reads, and it is a wall of plain text: "Qi: 0 / 300" floats
in the middle of an invisible progress bar (the ProgressBar has no style, so at 0 qi there is no trough at all),
"Lives 3    Spirit Stones: 10" is plain text, and the date/season/weather line is a 60-character string. Everything else
on screen (village, NPCs, buildings) is pixel art now; the HUD should look like it belongs.

## What to build (src/ui/hud.gd `_build_status_panel` / `_refresh`, src/ui/ui_style.gd)
1. **A styled qi bar.** `UIStyle.bar(size: Vector2, fill: Color) -> ProgressBar`: StyleBoxFlat trough (panel colour
   darkened, 1 px border in UIStyle's border colour, corner 2) and fill (`fill`, corner 2). Use it for `_qi_bar`
   (fill: a jade/qi colour, e.g. Color("6fd3c1"); keep the existing `modulate = ACCENT` bottleneck cue by swapping the
   fill colour instead of modulate). Text inside stays "Qi 0 / 300" (drop the colon), 12 px, outlined so it reads on
   both trough and fill. Reuse `UIStyle.bar` in the character sheet's qi bar (GFX-024) if it draws its own today.
2. **Lives as lamps.** Replace the "Lives 3" label with an HBox of small code-drawn soul-lamp icons (a 10x12 flame over a
   bowl, drawn once into an ImageTexture by a static `HudIcons.lamp(lit: bool) -> Texture2D`, cached): one lit lamp per
   life up to 5, then "x N" after the 5th lamp; 0 lives shows one unlit lamp plus "Final life" in the danger colour
   (keep `lives_text`/`lives_color` as the tooltip and colour source; existing tests on them must keep passing).
   Keep `_lives_badge` placement working (it anchors to the lives control).
3. **Spirit stones with an icon.** `ItemIcon.for_id(data, "spirit_stone")` at 1x (16 px) before the count:
   "10" instead of "Spirit Stones: 10". Other currencies `currency_line` shows (contribution etc.) keep their text.
4. **Date, season and weather as icons.** Split the date line: "Y1 M1 D1" text, then a 12 px season icon
   (spring blossom, summer sun, autumn leaf, winter flake) and a 12 px weather icon (clear, cloudy, rain, snow, fog,
   storm with a bolt), each from `HudIcons.season(name)` / `HudIcons.weather(kind)` (drawn in code, cached, unknown kind
   -> null and the text label is shown instead). Tooltip on the row keeps the full text, including "(tomorrow: X)".
5. **Spacing.** 2 px separation between rows (was 0), 8 px inner margin; the panel stays 316 px wide and must not grow
   taller than today's at day 0 (measure in the test below). `occupied_rects()` still returns the panel's rect.

## Files

- `src/ui/hud.gd`, `src/ui/ui_style.gd`, possibly `src/ui/character_sheet.gd` for the shared bar.
- `docs/ASSETS.md`: nothing (code-drawn).

## Tests (tests/unit/test_hud_icons.gd + existing hud tests)
- `HudIcons.lamp(true/false)`, every season and every `Weather.KINDS` kind return a non-null texture of the documented
  size; an unknown kind returns null.
- The HUD (instantiate like the existing HUD tests do) shows 3 lit lamps for 3 lives, 5 lamps + "x 2" for 7,
  one unlit lamp + "Final life" for 0; the stones label reads "10" with an icon.
- Status panel height at day 0 <= the pre-change height + 4 px (record the number in the test).
