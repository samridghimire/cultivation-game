# MED-001: Meditation preview (systems)

**Why:** "Meditate (1 month)" and "Closed-door cultivation (1 year)" say nothing about what they will do. The player cannot
tell that a year of meditation stops at a bottleneck after 40 days, or that this spot is twice as good as the last one.
WU-029 will show this preview in the menu's description line (ChoiceMenu, WU-022 / WU-027).

## Core (src/core/systems/cultivation.gd)
```gdscript
## What cultivating `days` at `density` would do, without changing `c`:
## {days: int (capped at the bottleneck), qi_gain: int, stages_gained: int,
##  realm_label: String (after), stops_at_bottleneck: bool, qi_per_day: float}
## days = 0 and qi_gain = 0 when already at the bottleneck or no qi is gathered.
static func preview(c: CharacterData, data: GameData, days: int, density: float = 1.0) -> Dictionary
```
- Compute on a copy: `var copy := CharacterData.from_dict(c.to_dict())`, cap `days` with `days_to_bottleneck(copy, data, density)`
  exactly like `GameState.cultivate` does (needed > 0 and needed < days -> days = needed), then `add_qi(copy, data, qi_per_day(copy, data, density) * days)`.
  If copying turns out costly or lossy, do the arithmetic directly with `realm.qi_required(stage)`; the result must match
  what `Cultivation.cultivate` would do (test below).
- `realm_label` is `realm_label(copy, data)`.

## Text helper (src/core/systems/guidance.gd)
```gdscript
## One line for a meditation menu entry, e.g.
## "About +1,240 qi (x1.8 qi here); you would reach Qi Refining 5th Layer."
## "Your qi reaches the bottleneck after 40 days; then attempt a breakthrough."
## "You are at a bottleneck: meditation will not help. Attempt a breakthrough."
static func meditation_preview(c: CharacterData, data: GameData, days: int, density: float) -> String
```
- Use `_commas` for the number. Mention the stage reached only when `stages_gained > 0`. When `stops_at_bottleneck` and
  `days` < requested, use the "reaches the bottleneck after <Calendar.format_duration(days)>" form. No spiritual root
  (`qi_per_day` 0) -> "Without a spiritual root, qi slips through you."
- `density` is shown as "x%s qi here" with `String.num(density, 1)`.

## GameState (src/autoload/game_state.gd)
```gdscript
## Preview line for cultivating `days` at a spot of `location_density` (same density as cultivate()).
func meditation_preview(days: int, location_density: float = 1.0) -> String
```
Uses `location_density * region_qi_density() * Sects.cultivation_bonus(player, data)`, the same formula as `cultivate()`;
extract a small `_cultivation_density(location_density)` helper and use it in both `cultivate()` and `dual_cultivate()`
so they can't drift.

## Tests
- test_cultivation.gd: `preview` matches a real `cultivate` on a copy (qi, stage) for 30 and 360 days from a mid-realm
  character; it caps days at the bottleneck; it does not change the input character (compare `to_dict()` before/after);
  at the bottleneck -> days 0.
- test_guidance.gd: the three text forms (normal with stage, bottleneck-capped, at bottleneck); no `%`/`{` in output.
- test_game_session.gd: `GameState.meditation_preview(30, 1.0)` is non-empty and contains "qi".
