# SIM-011: The hints player can follow every line

Role: systems (sim code in tests/sim). Reference: none (sim tooling). Follows SIM-010 (c3a8dca).

## Why
SIM-010's `hints` policy (tests/sim/first_hour.gd `_act_on_hint`, ~line 2071) is our best stand-in for a new player who
does what Next steps says. In 10 seeds x 365 days it could not act on these lines (counts are times listed while unactable):
1. "Your sect's home is Azure Cloud Hall in Azure Peak (N days by road): ..." x404 -> no travel-to-sect-home action.
2. "Unseal Storage Space in the artifact (O)" x377 -> no unseal action.
3. "Hunter Ma can teach you Iron Fist (favor N/N); ..." x370 and "Goal: Learn a fighting style" x355 -> no teacher visit.
4. "Headman Zhou has paid work: errands and chores." x360 -> a game bug, fixed by GUIDE-261 (not here).
321 of 520 weeks were idle, so the quiet-stretches number for "a player who reads the hints" is mostly a sim gap.

## What to build (tests/sim/first_hour.gd only, plus the sims that print it)
- (1) Sect home: `line.begins_with("Your sect's home")` -> `gs.travel(<sect home region>)` (find the region the same way the
  hint does; grep `_sect_hint` in guidance.gd), counting the trip days; once there, the next step may take the steward chore
  or mission lines that already work.
- (2) Unseal: the GameState action behind the artifact screen's unseal button (grep `unseal` in src/autoload/game_state.gd
  and src/ui); act when the line is shown, i.e. when the energy is enough.
- (3) Teacher: travel to the teacher's region if away, then do what raises favor the way a player would: the teacher's
  favor errand deeds (`deed_context` e.g. `hunter_ma_errand`), a liked gift if held or cheaply buyable, else a chat
  (the existing `chat_teacher` code path in first_hour.gd, reuse it); when favor is enough, learn the style
  (the same call the NPC menu's "learn" option uses).
- Keep the "given up after 3 acts" rule. Add a per-line tally of "acted / could not act" to `--hints` output so the next
  gaps are visible.

## Tests
`tests/unit/test_first_hour.gd` already toggles `hints_policy` (line ~172): add a short run (1 seed, 60 days) asserting the
policy learns a fighting style or reaches the teacher and that at least one unseal or sect-home action is taken when its
line shows (stage the state: artifact energy, a joined sect).

## Acceptance
`quiet_stretches.gd` hints row refreshed in the balance baseline (only that row and the new tally; default and curious rows
must not change). Commit message: before/after idle weeks and the new top 5 unactable lines as `Follow-ups:`.
No game code changes. tools/test.sh green. < ~300 lines.
