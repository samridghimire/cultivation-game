# BT-001: Breakthrough odds explained (systems)

**Why:** the breakthrough is the game's biggest gamble, and the menu only shows "Attempt breakthrough (47% chance)".
Players don't learn what moves the odds (pills for that realm, Fortune, Dao insights, bloodline) or where to get the pill.

## Core (src/core/systems/cultivation.gd)
```gdscript
## The terms of breakthrough_chance(), largest first, zero terms left out:
## [{label: String, value: float}], e.g. [{"Base (Foundation Establishment)", 0.30}, {"Foundation Establishment Pill", 0.25},
## {"Fortune 14", 0.04}, {"Dao insights", 0.05}, {"Bloodline", 0.03}]. Base is always present. Values sum (before the
## clamp) to the unclamped chance.
static func chance_breakdown(c: CharacterData, data: GameData) -> Array[Dictionary]
```
- Refactor `breakthrough_chance` to `clampf(sum of chance_breakdown values, 0.01, 0.99)` so the two cannot drift.
- The pending pill term is `c.breakthrough_bonus`; label it with the item name when `c.breakthrough_pill` names one,
  else "Pills and herbs taken". Negative Fortune (< 10) gives a negative term ("Fortune 7", -0.03); keep it.
- Final realm / no next realm -> [].

## Guidance (src/core/systems/guidance.gd)
```gdscript
## "Base 30% + Foundation Establishment Pill 25% + Fortune 4% = 59%." (percent rounded; "(capped at 99%)" when clamped)
static func chance_text(c: CharacterData, data: GameData) -> String
## Where to get a pill for the NEXT realm the player is not holding: "A Core Forming Pill (+25%) is sold at the
## Fallen Star Market's Pill Pavilion." Uses items whose effects.breakthrough_realm == the next realm id, picks the
## cheapest one with a source (Items.sources), "" if the player already holds a usable one (breakthrough_items),
## already took one (c.breakthrough_pill != ""), or none has a source.
static func pill_source_hint(c: CharacterData, data: GameData) -> String
```
- In `_cultivation_hint`, replace the generic " Breakthrough pills raise the odds." with `pill_source_hint` when non-empty
  (keep the generic sentence as the fallback).
- After a **failed** breakthrough, GameState posts one extra line: `pill_source_hint` if non-empty, otherwise
  "Fortune, Dao insights and pills raise your odds." (find the failure post in `attempt_breakthrough` in game_state.gd;
  category "progress" or whatever the failure line uses).
