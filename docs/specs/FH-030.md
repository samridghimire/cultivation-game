# FH-030: Honest newcomer hints and a first-goals ladder

Role: systems. Size: ~250 lines incl. tests. Files: `src/core/systems/guidance.gd`, `tests/unit/test_guidance.gd`,
`tests/unit/test_game_session.gd` (one integration check). No UI work (the journal screen already renders sections).

## Problems (audit 2026-10-08)
1. `_sect_hint` (guidance.gd ~287) lists every sect whose `Sects.check_join` passes. For a fresh Mortal at alignment 0 that is
   only the Blood Lotus Sect (data/sects.json: Blood Lotus admits mortals with alignment <= 0; Azure Cloud and Myriad Treasure
   need `qi_refining`). So the very first HUD hints tell a brand-new player "As a rogue cultivator you could join Blood Lotus Sect".
   The demonic path must stay a real option (DESIGN pillar 1), but the hint must not read as *the* recommended path.
2. `TECHNIQUE_HINT` (guidance.gd:13) says "Learn a technique from a manual. Merchants sell them." A new player has 10 stones and the
   cheapest manual costs 15; Elder Mo teaches the Basic Breathing Method for free (data/dialogue/elder_mo.json "breathing" node,
   offered while `not_knows_technique: basic_breathing`).
3. There is no explicit first goal: the newcomer hints are a flat list.

## Changes
### 1. Sect hint for Mortals
In `_sect_hint`, when `c` is rogue and their realm is `mortal`:
- `now`: sects whose `check_join` is ok; `later`: sects whose only failing requirement is the realm (build a copy with
  `CharacterData.from_dict(c.to_dict())`, set it to the sects' min realm stage 0 the way tests do, or add a small
  `Sects.check_join_ignoring_realm` helper; pick whichever is less code and say which in the commit).
- If `later` is non-empty: "Reach Qi Refining and %s will take you." % " or ".join(later). If `now` is also non-empty, append
  " %s takes mortals now, but walks a demonic path." for each `now` sect whose `max_alignment` <= 0 (otherwise just " %s takes
  mortals now.").
- Not Mortal: unchanged.

### 2. Technique hint
Replace the constant use in `_newcomer_hints`: if `c.techniques` is empty, then
- if Elder Mo's lesson is still available (`not c.techniques.has("basic_breathing")` - already implied - and
  `data.techniques.has("basic_breathing")`): "Elder Mo in Qingshi Village teaches a breathing technique for free.";
- else keep `TECHNIQUE_HINT`.
Check the ordering still puts "Ask Elder Mo..." first; when both Elder Mo lines would show, merge them into one line:
"Ask Elder Mo in Qingshi Village where to begin; he also teaches a breathing technique." (no duplicate Elder Mo lines).

### 3. First goals
New `static func first_goals(c: CharacterData, data: GameData, flags: Dictionary) -> Array[Dictionary]` returning, in order,
`{text: String, done: bool}`:
1. "Talk to Elder Mo" - done when `flags[ELDER_MO_FLAG]`.
2. "Learn your first technique" - done when `not c.techniques.is_empty()`.
3. "Reach Qi Refining" - done when realm index >= 1.
4. "Join a sect, or explore the wilds as a rogue" - done when `not c.is_rogue()` or `LifeStats.get_stat(c, "encounters") >= 5`.
5. "Win your first fight" - done when `LifeStats fights_won >= 1`.
6. "Reach the 3rd Layer of Qi Refining" - done when realm index > 1 or (realm index == 1 and stage >= 2).
Use the real accessor names from life_stats.gd / character_data.gd.

`static func first_goals_done(c, data, flags) -> bool`: all done.

In `journal(...)`: while not all done, add a section "First goals" **before** "Next steps": one entry per goal, text prefixed
"[x] " when done (tone "dim") and "[ ] " when not (tone "normal"; the first undone goal gets tone "warning" so it stands out).
After all are done the section disappears.

## Tests (test_guidance.gd)
- Fresh mortal (alignment 0): sect hint mentions "Reach Qi Refining" and Azure Cloud, and if Blood Lotus is named it is with
  "demonic"; it never starts with "As a rogue cultivator you could join Blood Lotus".
- Qi Refining rogue: old wording unchanged.
- Mortal with no technique, Elder Mo flag unset: exactly one line contains "Elder Mo"; it mentions the breathing technique.
- Mortal who knows a technique: no technique line.
- `first_goals` on a fresh character: 6 entries, none done; with the flag, a technique, realm QR stage 2, a sect and one
  fight won: all done and `journal` has no "First goals" section.
- The first undone goal is the only "warning" entry in the section.
- No goal text contains `%`, `{` or `<null>`.
## Integration (test_game_session.gd)
- New game: `Guidance.journal(...)` via GameState (whatever the journal screen calls) has a "First goals" section.

## Acceptance
`tools/test.sh` prints ALL CHECKS PASSED; existing guidance tests updated only where the wording changed on purpose.
