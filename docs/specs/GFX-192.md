# GFX-192: A world map that looks like a map

Role: world-ui. Reference: Wandering Sword's painted world map (look only: no layout, names or art copied).
Planner shot 2026-11-18 00:10 (`screenshot_screens.gd` map.png, 1280x800): the World Map is a plain parchment grid with
seven beige boxes (dotted outline when unexplored), dotted red/brown route lines, day tags and small terrain marks scattered
around each box. It reads as a diagram, not a land. The details panel on the right is fine; change only the left canvas.

## What to build (src/ui/world_map_screen.gd, draw-only)
1. **Land washes.** In `_draw_land`, before the vignettes, paint one irregular land patch per region under its node:
   a seeded blob (rng seeded by `hash(region_id)`, as the vignettes do) of 10-14 points around the node rect grown by
   ~28 px x 18 px, filled with `land_color(region)` at alpha 0.35 (0.18 when unexplored), and a 2 px darker ink edge
   (land_color darkened 0.35, alpha 0.5) drawn as a polyline. Edges are pixel-stepped (snap points to a 2 px grid), not
   antialiased, to match the pixel-art direction. Patches may overlap; draw them in sorted id order.
2. **One river.** A seeded meandering line (3 px, `Color(0.35, 0.55, 0.7, 0.7)`, 1 px lighter centre) from the top edge
   above Azure Peak's node, passing between Myriad Peaks Ridge and Withered Bone Marsh, to the bottom edge east of the
   Fallen Star Market. Compute its control points from the node positions (`_positions`), never hard-coded pixels, so a
   layout change moves it. It must not cross any node footprint (`node_footprint`): test this.
3. **Nodes as map labels, not boxes.** Replace the box stylebox in `_style_node` with a label on a small paper banner:
   bg `Color(0.96, 0.92, 0.8, 0.92)`, 1 px ink border, 2 px corner radius, and two 3x5 px "scroll ends" drawn at the left and
   right of the rect on the canvas (darker paper). Unexplored: keep the dotted outline (WU-530) and the faded text; the
   "Unexplored" second line stays. Hover/focus keeps the ACCENT border (gamepad focus must still be visible).
   Keep `node_rect`/`node_footprint` sizes unchanged so `day_label_pos`, `clip_to_rects` and every layout test still hold.
4. **Routes as roads.** `_draw_dotted` routes become short dashes (4 px on, 3 px off, 2 px thick) in the same colours
   (ROUTE_COLOR / LOCKED_COLOR); the unexplored-node outline keeps the dots.
5. Keep the current-region seal, goal and "!" markers, the marks row and the day tags exactly as they are, drawn on top.

## Tests (extend tests/unit/test_world_map_screen.gd or test_world_map_layout.gd)
- `river_points(positions: Dictionary, rects: Dictionary) -> PackedVector2Array` is a pure static helper; for the real
  data layout, no river segment intersects any node footprint, and the first/last points lie on the canvas top/bottom edge.
- `land_patch(region_id, rect) -> PackedVector2Array`: deterministic (same id -> same points), every point within the rect
  grown by 40 px, at least 10 points, all on even coordinates.
- Existing map layout tests pass unchanged.
