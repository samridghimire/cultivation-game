# QA-048: A curious player who tries everything (QA-041 Follow-up)

**Why.** QA-041 found the median curious player does exactly 2 kinds of action a month (explore + sect mission) from month 7
to 36, but the policy never crafts, works a profession, enters a secret realm, gives gifts, asks for pointers, spars,
attends the lecture or travels. So the sim measures the policy, not the game. Teach it, then find the real dull stretches.

## Change tests/sim/first_hour.gd `_curious_month` (keep the default newcomer policy unchanged)
Each month, after the existing steps, try each of these once, only through the same GameState calls the menus use, and only
when the core check says it is allowed (never force anything), recording the kind in `kinds`:
1. **travel**: every 6th month, if `Guidance.unexplored_routes(c, data, current_region)` is non-empty, travel to the first,
   explore 7 days there (`explore_many(7)`), then travel back to the start region. Kind "travel".
2. **craft**: if the player knows a recipe (`c.recipes` or however recipes are stored) whose ingredients are in hand, craft
   it once (`GameState.craft` or the crafting screen's call). Kind "craft".
3. **profession**: if the player has no profession and one is learnable here (`Professions` join check), take it the first
   time (pick the first allowed in data order); afterwards do one profession work action a month if one exists. Kind
   "profession".
4. **gift**: give the cheapest giftable item held to the NPC with the highest favor (`Family.gift_value` > 0). Kind "gift".
5. **pointers / spar**: `GameState.check_pointers(npc)` == "" for any NPC in the region -> ask; else a spar if allowed.
   Kinds "pointers", "spar".
6. **lecture**: if in a sect and the lecture is available this month, attend. Kind "lecture".
7. **secret realm**: if an open realm's `SecretRealms.check_enter` passes and the player is not below its realm cap, enter
   and clear one floor (or whatever the screen does), retreating if the next floor is Deadly. Kind "secret_realm".
8. **deeds**: replace the `done` set for deeds with the real rule: skip a deed only when `Deeds.options` marks it disabled
   (cooldown/once); QA-041 found deeds stop after month 1 only because of the sim's done-set.
Find the exact GameState function names by grepping; if one of these has no GameState action, skip it and say so.
