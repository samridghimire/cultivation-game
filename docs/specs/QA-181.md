# QA-181: A year of village life, measured

Role: qa. Reference: Immortal Life's loop of field, pond and kitchen (we check ours is worth a player's days).

## Why
FARM-001, FISH-001/002, MARKET-001, WORLD-007 and FOLK-004 all landed with "sims never use it: no balance run". Nobody knows
whether a field plot or a day of fishing pays anything next to the Doctor's ~15 stones a month or a day of meditation.

## What
1. Add `--village` to tests/sim/first_hour.gd (and the `play_cached` memo key, like `--heal-injuries`): in Qingshi the sim
   rents the field plot when it holds a plantable herb and 6+ stones, plants, harvests when ready, fishes on rain days (or
   one day in 7), cooks a meal when injured, sells catches/crops at the merchant (seasonal prices), and takes tea when a visitor
   comes. Otherwise it behaves as the base sim.
2. Run `tests/sim/simulate_curious_years.gd -- 10 12 --village` and the base arm; report in the commit:
   - stones earned per day spent for: field (rent + days spent planting/harvesting vs crop sale value), fishing, Doctor work;
   - months to Qi Refining and to the 3rd layer (village vs base);
   - quarrels met/settled, visits, favor gained.
3. Judge against DESIGN.md pillar "every path has real choices": a village day should earn within 0.5x-1.5x of work per day.
   If one is far outside, do **not** retune here: write `Follow-ups:` with the numbers and a proposed data change
   (regions.json field plot rent/yield, fish prices in items.json, family.json folk_visits).
4. Add a unit test that the `--village` policy functions pick the plant/harvest/fish actions in a tiny seeded scenario (the
   test file the other sim policies use).
No game code changes. Under ~300 lines.
