# GFX-001: sprite pipeline with `_draw()` fallback

Owner decision 2026-10-28 (DESIGN.md "Art direction"): top-down pixel art from CC0/CC-BY packs, placeholders stay as the
fallback. No pack is in the repo yet (GFX-002 waits on the owner), so this task builds the plumbing and ships **no binary
assets**. Reference: Wandering Sword (readable top-down pixel towns and characters); take the look, never its art.

## Files
- `data/sprites.json` (new). `_doc` explains every field. Shape:
  ```json
  {"_doc": "...",
   "tile_size": 16, "scale": 2,
   "packs": [],
   "sprites": {}}
  ```
  `packs`: `[{id, name, author, license, url}]` (credits). `sprites`: key -> `{path: "res://assets/...png", region: [x, y, w, h]
  (optional, whole texture when absent), frames: int (optional, default 1, laid out left to right), fps: float (optional),
  pack: pack id}`. Keys used now: `player_down`, `player_up`, `player_left`, `player_right`, `place_<kind>` for every
  `PlaceArt.KINDS` entry, `npc`. Ship the file with empty `packs` and `sprites`.
- `src/world/sprites.gd` (new), `class_name Sprites extends RefCounted`, `##` doc comment, all static:
  - `static func texture(key: String) -> Texture2D`: an `AtlasTexture` for `region` (or the plain texture), loaded once and
    cached; `null` when the key is missing, the path does not exist (`ResourceLoader.exists`) or loading fails. Never errors.
  - `static func frame(key: String, index: int) -> Texture2D`: frame `index % frames` of a strip.
  - `static func fps(key: String) -> float`, `static func scale() -> int` (from the json, default 2).
  - `static func override(key: String, tex: Texture2D) -> void` and `static func clear_overrides() -> void` for tests.
  - `static func credits() -> Array[Dictionary]`: the `packs` list.
  - The json is read with `FileAccess` + `JSON.parse_string` once (static var cache). This lives in `src/world`, not
    `src/core`: core stays free of rendering, and `GameData` does not load this file.
- `src/world/player.gd` `_draw()`: when `Sprites.texture("player_" + dir)` exists (dir from `_facing`: the larger axis),
  draw the current walk frame (`Sprites.frame`, advanced by `_time * fps` while moving, frame 0 standing) centred on the
  feet at integer `Sprites.scale()`, after the shadow and aura, and skip the robe/head polygons. Tint: keep the sash line
  and aura drawn as today on top/under so sect and alignment still read (robe tint by `modulate` is optional; don't tint
  the whole sprite). Otherwise today's drawing, byte for byte.
- `src/world/interactables/interactable.gd` `_draw()` (~314): when `Sprites.texture("place_" + art_kind)` exists, draw it
  centred, scaled to fit `size` at an integer factor, instead of `PlaceArt.draw`; the anchor ring, highlight and label stay.
- `src/ui/credits_screen.gd`: an "Art" section listing `Sprites.credits()` (name, author, license); hidden when empty.
- `docs/ASSETS.md`: replace "No binary assets are shipped yet" with a table header `| file | pack | author | license | url |`
  and one line saying sprites are mapped in `data/sprites.json`, packs live in `assets/third_party/<pack>/` with their
  license file, and CC-BY authors appear on the credits screen.

## Edge cases
- Missing or malformed `data/sprites.json`: everything draws the placeholder; push no errors in tests.
- A sprite whose `path` is set but the file is absent (pack not yet committed): placeholder.
- `project.godot` already has `default_texture_filter=0` (nearest); keep it. Don't change stretch settings in this task.
