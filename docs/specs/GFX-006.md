# GFX-006: sprite hooks for terrain, paths, decor and NPCs

GFX-001 (on main, 5509620) wired `Sprites` into the player, place art and credits. The rest of the world map still draws
only `_draw()` shapes: the ground is one flat `draw_rect`, paths are flat rects, decor (tree/rock/grass/flower) is circles
and polygons, and NPCs use the place-art path. This task adds the remaining **hooks** so that, once a pack is committed
(GFX-002, blocked on the owner), dressing a region is a pure `data/sprites.json` edit. **No binary assets.**
Reference: Wandering Sword (tiled top-down towns where ground, paths and props read at a glance); mechanics/look only.

## Keys (document all of them in data/sprites.json `_doc`)
- `ground_<region_id>` then `ground` (fallback): one tile, drawn tiled over the whole map.
- `path_<region_id>` then `path`: one tile, drawn tiled inside every `map.paths` rect (clipped to the rect).
- `decor_<kind>` for every `Scenery.KINDS` entry (`decor_tree`, `decor_rock`, `decor_grass`, `decor_flower`).
- `npc` (already listed by GFX-001; make sure it is used, see below) and `npc_<npc id>` before it for named NPCs.

## Files
- `src/world/sprites.gd`: add `static func first(keys: PackedStringArray) -> Texture2D` (first non-null `texture(key)`, else
  null). Keep everything else.
- `src/world/world.gd` `_draw()` (~378):
  - Ground: `var tile := Sprites.first(["ground_" + region_id, "ground"])`. When non-null, tile it: step =
    `tile.get_size() * Sprites.scale()`, loop rows/cols over `map_size` with `draw_texture_rect(tile, Rect2(pos, step), false)`
    (the last row/col is clipped by `draw_texture_rect_region` or simply overdrawn by the border; either is fine). Otherwise
    today's flat `draw_rect`, byte for byte.
  - Paths: same with `path_<id>`/`path`, per rect, clipped (use `draw_texture_rect_region` for the partial last tile).
  - Performance: the world `_draw()` runs only on `queue_redraw()`; check it is not called every frame (grep
    `queue_redraw` in world.gd). If it is, cache the tiled ground into an `ImageTexture` once per region instead. A
    1600x1000 map at 32 px per tile is ~1600 draw calls, fine for a one-off redraw.
- `src/world/world.gd` `_draw_decor(d)`: when `Sprites.texture("decor_" + d["kind"])` exists, draw it with its bottom
  centre at `d["pos"]`, at integer scale `maxi(1, roundi(Sprites.scale() * d["scale"]))`, tinted with `Color.WHITE` (do not
  apply `d["color"]`; pack art is already coloured). Otherwise today's shapes.
- NPCs: find how an NPC is drawn today (`src/world/interactables/npc.gd`, it extends `Interactable`, so probably
  `PlaceArt.draw` with an npc `art_kind`, or `PlayerLook`). Before that drawing, try `Sprites.first(["npc_" + npc_id, "npc"])`
  and draw it like the player sprite (frame 0, feet at the bottom centre, integer `Sprites.scale()`); keep the label,
  highlight and any sect/alignment cue drawn on top.

## Edge cases
- No sprites mapped (today): every screen looks exactly as before. The scene smoke tests and screenshot scripts must not change.
- A key whose file is missing: placeholder (Sprites already returns null).
- Do not move decor placement logic out of `Scenery` (core); only the drawing changes.
