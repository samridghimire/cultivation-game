# GFX-241: Disciples at their drills (world-ui)

**Reference:** Wandering Sword's sect grounds, where disciples practise in the courtyard (look only, never its art).
**Why:** Azure Peak's court in front of Azure Cloud Hall is an empty paved square (planner shot 2026-11-22 18:10
region_azure_peak.png). A sect home should look like a sect lives there, the place a new disciple walks 10 days to reach.

## Data
- data/sects.json: optional per-sect `"court_drill": {"count": int 2-6, "form": "sword" | "fist" | "ledger"}`. Document in
  `_doc`, validate in GameData (count range, form enum). Set Azure Cloud: 6 sword; Blood Lotus: 4 fist; Myriad Treasure
  Pavilion: 2 ledger (clerks with a board instead of a drill), or omit it for the Pavilion if it looks wrong.

## Drawing (new src/world/court_drill.gd, a Node2D added by world.gd only in a region that is some sect's `home_region`
and whose sect has `court_drill`)
- Positions: pure static `CourtDrill.positions(court: Rect2, count: int, door_x: float) -> Array[Vector2]`: two rows inside
  `SectCourt.court_rect(...)` (use whatever SectCourt exposes; read sect_court.gd), at least 28 px from the court edges, keeping a
  free column of 48 px centred on the hall door so the player's walk to the hall is never blocked, and at least 22 px apart.
- Figures: reuse the person-drawing helper NPCs use (find how interactable NPCs draw their body; robe in the sect's
  `robe_color`), no name plates, not interactable, no collision. Pose loop: 3 poses (ready, thrust/strike, return) ~1.2 s
  each, all figures in step except a small per-row lag (0.15 s) so it reads as a drill. "ledger" stands still with a small
  board and turns a page every few seconds. Use `_process` only while the node is visible; no per-frame allocation.
- None on days with rain or storm (`Weather.of(...)`), none at night if the world draws a night phase (check NightGlow),
  none during a festival that already crowds the court.
- Draw order: above the court's paving, below place labels and NPC name plates. Must not cover a named NPC's stand (re-use
  `SectCourt.settle_stand` spots as blockers) or the hall's [E] prompt.

## Tests (tests/unit/test_court_drill.gd)
- positions inside the court, none in the door column, pairwise >= 22 px, deterministic for the same input;
- no drill node in Qingshi; none in Azure Peak on a forced rain day;
- GameData rejects `court_drill.count = 9`.

## Acceptance
Render `--region=azure_peak,withered_bone_marsh,fallen_star_market` at 1280x800 and open each: figures in robes in the court,
the path to the hall door clear, no figure under a name plate. tools/test.sh green. No new binary assets.
