# GFX-068: Azure Peak looks like a sect's mountain (world-ui)

Reference: Wandering Sword's sect towns (a stone gate, steps up to a hall, a clean paved court in front of it). Mechanics
and composition only, no art.

Planner shot 2026-11-05 (`screenshot_first_hour.gd -- --great --region=azure_peak`, 1280x800): the whole ground is a
dark blue-grey speckle like the marsh was before GFX-062, so the region reads as dreary noise; the Azure Cloud Hall
(home of the sect most players join) is a small blue house at the bottom edge, indistinguishable in weight from the
Hermit Forge; nothing says "you are entering a sect".

## Do
1. **Calmer mountain ground** (GroundTiles, the tag Azure Peak uses): halve the dark speckle and lift the base colour a
   step, as GFX-062 did for bog ground (add a speckle-bound test like GFX-062's). Snow days must still read as snow.
2. **The sect court.** A sect hall place with a `sect` (MISSION-002's field) draws a paved stone court around its rect
   (flagstone pattern like the market street, ~1.6x the hall's footprint) with three short steps up to the door and
   two stone lanterns. Pure helper for the court rect so it never covers a path or another place (test).
3. **A mountain gate.** On a region whose home sect has a hall there (azure_peak; the marsh's Blood Lotus Reed Hall
   gets the same with dark red posts), draw a gate arch (two posts, a roof beam, a name board) where the main path
   enters the region (the edge the "Mountain Path" exit uses). PixelLandmark or a new small node; no collision change.
4. The hall label and the gate must not collide with other labels (LabelLayout).

## Tests
Speckle bound for the mountain ground; court rect inside the region and clear of paths/places for both sect halls;
the gate is built only for regions with a sect hall that has `sect`.
