# LOG-004: A log you read every line of

Role: systems. Reference: Immortal Life's daily log (one line per thing you did), mechanics only.

## Problem
LOG-003 brought the first-hour log to 11.4 lines/month (target 9.5) and the curious player to 69-79. Its commit says
progress and info are now the loudest categories. The "log noise" section of docs/balance_baseline.txt is stale (it still
lists "Tomorrow: ..." lines LOG-003 removed), so measure first.

## Steps
1. Run `tools/godot.sh --headless --path . -s res://tests/sim/log_noise.gd` (see the header of tests/sim/log_noise.gd for
   arguments) and paste the top-15 template table into the commit message as "before".
2. Thin these (each is a known loud line; check it is still in the top 15 before touching it):
   - **Practice and cultivate summaries.** "You practice the X for N days." (game_state.gd ~2877) and "You cultivate for N and
     gather N qi (...)" (game_state.gd ~226): when the same action repeats back to back on the same day chain (the sim and a
     player pressing it again), fold into the previous line instead of a new one. Add a small core helper
     `LogFold.fold(prev_text: String, prev_day: int, new_text: String, day: int) -> String` in `src/core/systems/log_fold.gd`
     (pure; returns "" when not foldable) that merges "You practice the Iron Fist for 5 days." + "... for 5 days." into
     "... for 10 days." (same technique, same template, previous line posted <= 1 day before). GameState keeps the last posted
     line + day per category and asks EventBus to replace the last log entry (add `EventBus.replace_last(text, category)` if
     the log has no such call; the HUD log must refresh that row, not append).
   - **"<name> is delighted."** (game_state.gd ~2404): post it as part of the gift line ("You give X to Y. Y is delighted.")
     instead of a second line.
   - **Weather forecast** "Expect mostly <w> weather in <region>." (guidance.gd ~178): only into the log when it differs from
     the last forecast posted for that region, or is rain/snow/storm; otherwise Today/HUD only.
   - **Great beast** "Tomorrow: The <beast> walks <region>.": only when the player is within 3 travel days of that region, has
     an open hunt task naming it, or has baited its trail.
3. Re-run log_noise and `tools/balance.sh` (first hour, curious first hour, log noise sections: refresh them). Targets:
   first hour <= 9.5 lines/month median, curious <= 65. If not met, list the next loudest templates under `Follow-ups:`.

## Tests
- tests/unit/test_log_fold.gd: folds same template/technique within a day; does not fold different techniques, different
  templates, or a gap of 2+ days; returns "" for unrelated lines.
- GameState integration (tests/unit/test_game_session.gd pattern): practising Iron Fist twice in a row leaves one log line with
  the summed days; a gift a liked NPC loves posts one line containing "is delighted".
- Forecast: the same "mostly clear" forecast two days running posts once.

## Acceptance
All tests pass, balance sections refreshed with the before/after numbers in the commit, no message content lost (the folded
line still says how long you practised / how much qi you gathered in total).
